0. 一句话

人不是重放题，是重放经历。 现在 Δ 的保真度 99.6 % 是在 186 道题（格点）上量的，不是在 19,829 个位置（历史）上量的——这两件事的差别，就是这条支线的题目。

1. 本轮被收窄或撤回的三条

R1 「压缩 KV / soft token 当第四种载体，就地、免费、精确」——【已撤回】

我上一轮说可以直接改 KV 而不训练。错在两点：

（a）soft token 要付膨胀率。 一个 soft token 不是"一个数"，是一整条全宽 KV 行：本引擎 2 × 16 层 × 4 KV头 × 256 头维 = 32,768 个值 = 64 KiB（与 A1 的 KV 记账同源）。所以预算反过来算：

值数 折成 soft token
Δ（11.0 MiB BF16）5,767,168恰好 176 行
2,048 个 soft token67.1 M128 MiB = Δ 的 11.6 倍

拿 Δ 的字节预算去开 soft token，只够 176 个位置。Δ 是函数，soft token 是表：表的 176 行按位置寻址、只在自身之后生效；Δ 的 5.77 M 参数被每个位置复用，拿到的是全域梯度。这与 prefix/soft-prompt 在知识注入上属于最弱一档 PEFT 的经验一致——它是控制旋钮，不是记忆。

注意：本条对更大模型更不利（每 token KV 随层数/头数上升），不是更有利。

（b）蒸馏 KV 要反传，那就不是"拷一份"，是"拟合一份"。 要让 KV 表现得像教师，就得对 KV 求梯度。而这条反向更重：KV 前缀是 N 个全宽状态，梯度穿每个位置的 attention；Δ 只在 down_proj 上，反向是 $O(|R| \times \text{rank})$。同一笔写钱，更差的基底、更坏的条件。 所以它不是第四种载体，是第三种载体的一个劣化实现。

R2 「迭代压缩 N 次会不会崩」——【旁支，不是 dream 的内容】

我把它当成了"稳定性状态"的回答。它本身是个值得做的稳健性问题（v10 只测了一次压缩，生产压 N 次），但它回答的不是用户问的那件事。降级为旁支，见 §6。

R3 我误读的两个地方

  • "probe = 压缩比"我读成了 decode 审计成本。实际指的是重放预算，不是推理时的探针。
  • "dream"我读成了稳定性，实际指的是probe 怎么选——重放集本身就是机制。

2. 两条候选律，只能选一条

用户本轮澄清："人脑相当于一直在 decode，24 h 睡 8 h ⇒ 重放/做梦的 decode 总位置数至少应等于今天 H 的一半。"

律 形式 分母 含义
L1压缩律重放量 ∝ rr压得越狠，夜里越久
L2值班律重放位置 ≥ (1/3 ~ 1/2)·|H||H|同底同速 ⇒ 值班比决定预算

两条不能同时成立（除非值班比本身随 r 变，而它不变）。采纳 L2【假设】：分母是"今天"，不是"压了多少"。

L2 的两个数字【算术】：

  • 人类串行：\|H\|=200 k，一半 = 100 k 位置 ÷ 9.8 tok/s（bench_q35.json）= 10,204 s = 2.83 h，落在睡眠里真正做梦的 1.5–2 h（数个 REM 周期）之内。
  • LLM 并行：batch 333、103.4 ms/step ⇒ 一遍 300 步 = 31.1 s，64 遍 = 33 min。

即：8/24 不是选的，是同底同速的必然；并行不改变位置数，只压掉墙钟。 这也是唯一能让类比不显任意的读法。

3. 实测：现在 Δ 的重放根本不是 O(|H|)

这是本轮最硬的一条，也是 L2 与现状的冲突点。梯度预算实际是 $O(\text{格点} \times \text{遍数})$，不是 $O(|H|)$：

实验 唯一项 遍数 访问数 结果 状态
m28_stepsweep36 探针4 / 8 / 16 / 32144 → 1,152train top1 .316 → .390 → .529 → .805【已测】32 遍仍在涨，未收敛
m49_budget186 探针12823,808canonical 1.000（C128）/ .960（B128）【已测】
m43_batch9,984 样本64638,976canonical .9960；held-out：P1 .9688、diff_fact .9500、paraphrase .9875【已测】

三点读法：

  1. "多少重放才够"现在的答案不是"要很多"，而是"要少而重复"。 m49 用 186 项 × 128 遍就把 canonical 顶到 1.000；m43 用 9,984 项 × 64 遍拿到 .9960。前者 23.8 k 次访问，后者 639 k 次访问——访问数差 27 倍，保真度只差 0.4 个点。 这本身就是"课程 > 覆盖"的苗头，但两套 setup 不同，不能直接当证据。
  2. m28 是唯一能看到收敛形状的：32 遍还在爬，且 effective rank 从 3.51 掉到 1.39（Δ 容量 64）。这与既有结论"瓶颈是写的填充、不是载体容量"一致——同一个现象：多跑遍数在把 Δ 往更低秩推。
  3. 顺带一个巧合：m43 的 9,984 恰好是 \|H20\| = 19,829 的 50.35%。是巧合就别当证据；但它至少说明 L2 那个量级不是随手写的。

E0 —— 忠实拟合有没有拟合到"风格"【待定｜零训练，最先做】

目标就是复刻 H Teacher 的分布，风格与信息在同一个 KL 里，不是二选一。所以问题不是"要不要风格"，而是"现在的忠实拟合有没有到那一层"。拿 m43 / m49 的已有 checkpoint，把 held-out 探针的逐位置 KL 按 token 类别切开（事实位 / 非事实位），与 base 比：

  • 非事实位 KL 已接近教师 ⇒ 风格随忠实拟合免费得到，E2 只需测泛化，写侧不必改；
  • 非事实位 KL 明显高于事实位 ⇒ 现在的写是事实偏置的，要改支撑（见 E2）或改 loss 权重。

不需要重训、不需要新历史。这一步决定后面是"测泛化"还是"改写"。

E1 —— 值班律 vs 压缩律【待定】

固定 \|H\|，只扫 \|S\|，测收敛所需的重放访问数 $N^*$。

  • L2 预测：$N^*$ 平（分母是 \|H\|）。
  • L1 预测：$N^*$ 随 r 上升。

分两档：

  • 便宜档（现在就能跑）：H20 上 \|S\| ∈ {2.5 k, 5 k, 10 k}，即 r ∈ {7.9, 4.0, 2.0}。只测单调性（$N^*$ 是否随 r 变），不测斜率。
  • 工作点档（要新历史）：r 落在 bracket [77.5, 154.9] 需要 \|H\| ≈ 250 k、\|S\| ≈ 2.5 k。生成器放大即可（~1,300 事务 × 150 实体 ≈ 900 格），教师前向 16 GiB KV（按本引擎 64 KiB/token 计），可行。【推论】

判据：把 $N^*$ 定义为 held-out top1 达到 canonical 平台 95 % 所需访问数，避免"跑到收敛"的主观阈值。

E2 —— 课程 vs 覆盖（这才是 dream 的正门）【待定】

等访问预算 ≈ 23.8 k，两条路：

臂 重放对象 访问数 备注
少而重复186 个格点 × 128 遍23,808m49 已有两臂，可直接当基线
多而一遍|H20| 的一半 = 9,914 个位置 × 1 遍（位置级 KL）9,914新跑

"位置级重放"的定义：在 H 中采样位置 $t$，教师看全 H，学生只看 $E+R+q$（该位置的局部尾），在位置 $t$ 上做全词表 KL。这就是"重放经历"的形式化，与现在的"格点问题"是同一个目标函数、不同的重放对象。学生侧 $O(|R|)$，9,914 位置 / batch 333 ≈ 30 批，成本与 m43 同量级。

  • 若覆盖赢了：只重放位置、从没在任何格点上训练，却恢复了格点保真度——这是"梦境能把经历压成记忆"的最强证据。
  • 若格点赢了：课程 > 覆盖，且证明了 v10 的做法不是偷懒。

"我全都要"之后，这条实验的意义升级了。 现在的格点课程，训练分布的支撑只有"问题→答案"；非事实位（虚词、标点、连接词）只出现在答案内部的少数 token 上。也就是说风格在当前课程下物理上不在训练分布里——不是权重给得小，是支撑根本不到。而位置级重放按构造覆盖 H 的每一个 token，于是 E2 的问题从"课程 vs 覆盖"变成：

复刻答案，还是复刻教师？ 格点重放是位置重放的子集。

这也给了 E0 的两种结局各自的下一步：非事实位没拟合上 ⇒ 换支撑；拟合上了 ⇒ 只需在未见内容上测泛化。

两个回落风险要提前写进设计：位置级 KL 的 $\|S\|$ 依赖（位置越早、Δ 越远，权重怎么定）没有现成说法；以及 9,914 与 23,808 只是同量级，不是等预算，报告时必须并列绝对预算而不是比值。

E3（暂缓）顺序

人脑重放是串行交错的，干扰与巩固都在顺序里；Δ 现在是 IID 批拟合，等于"从不做梦"。等 E2 有结果再谈。

E4 —— 忠实重放 vs 污染重放（"dream" 这个名字的判据）【待定】

E1/E2 都不碰梦最扎眼的特征：重组与荒诞。IID 采样只给"跳"，不给"合成"。

Hoel 的 overfitted brain 假说给了一个可操作的解释：梦是故意加噪的输入，用来防止巩固把系统过拟合到当天的样本（引用与出处待核，未读原文）。若成立，重放就该被故意污染——而现在 Δ 是忠实拟合教师，等于"做梦不许走样"。

固定同一预算（建议 23,808 次访问，与 E2 对齐），四臂：

臂 重放目标 预期
F 忠实现状：teacher on H保真度上界、泛化下界
D_topic 内容污染保留句式，实体值换成 frame 内其它实体事实位 KL ↑，非事实位不变
D_style 形式污染保留事实，改语域/措辞事实位不变，非事实位 ↑
N null同范数随机低秩 ΔW所有指标必须回落到 base

D_style 的算子是现成的：m48_pool.json 每格 10 条 paraphrase，m48_forms.json 已测两个语域池（口语 / 正式）的保内容率 85.96 %（49/57）与 93.33 %（56/60）——即"改形式、留事实"这个操作本身是有实测支撑的，不是口头假设。

因变量必须分层，否则"变像了"分不清是风格变了还是把词换了：

  • 逐位置 KL 按 token 类别切开——事实位（数字/实体）vs 非事实位（虚词/标点/连接词），即"风格可归因 KL"，可复用既有 mask 事件管线；
  • 自由生成 PPL（不 teacher-forced），暴露 teacher-forced 掩盖的偏差；
  • held-out 格点 top1（保真度）；
  • 结构层/词汇层的 JS + 判别器 AUC，作零 GPU 的下界证据。

有效性纪律先过再报数（细则见 STYLE-METRICS-v1.md §4）：null 必须回落；长度直方图匹配重采样；锚点排序自检（同作者 / 同领域 / 跨领域须给出同一序）；"没测出差异"不写成"等效"，要 TOST 且等效界预先声明。

判据（预先声明）：若 D_topic 的 held-out 格点 top1 显著高于 F（配对 bootstrap，CI 不跨零），则"走样是功能"——这个名字叫 dream 才有内容；否则荒诞只是副产物，名字收回成 replay。

成本：三次同预算训练（与 m43 同量级）+ 零 GPU 指标，约一天。不需要新历史、不需要放大生成器，所以排在 E1 工作点档和 E2 之前。

E5 —— 外界纠错作为重放单位（"经验" vs "事实" vs "蕴含"）【待定｜攻击性最强】

对象不是"蕴含"，是信念被外部推翻的记录。它和 A→B 的差别在"目标能否由自己生成"：

重放单位 目标能否由模型自身生成 判定
事实 B能（权重里就有，且 frame 内高度冗余）冗余
蕴含 A→B能推可约
纠错记录（以为是 X，世界说 ¬X）不能外源锚

这也顺手解掉了我提过的一个矛盾（"最大梯度落在教师最不可靠处"）：纠错记录的目标由环境给出——工具输出、非零退出、用户驳回——不是教师断言。所以在这一类上，教师的可靠性问题消失了。

（a）C 臂的四段式模板。 缺一段就不算 C：

先验   我预计 <X>                  ← 动作前的断言
动作   <命令 / 调用>                ← 可重放的外部交互
反证   <报错 / 非零退出 / 返回 Y>    ← 外部锚，必须能定位到具体输出
修正   改成 <Z>，因为 <理由>         ← 修正后的行为

只取"修正"、不取"先验"，学到的只是新值，不是"我错了"这件事。

（b）外部锚的定位规则（可自动切分，零成本）：exit code != 0；错误消息后紧跟参数变更的重试；用户在 3 轮内出现"不对 / 不是 / 但是"；自述型纠正（"我记错了""实际上"）。四条都能正则化地捞。

（c）必须拆"值"和"事件"。 修正后的值仍是点事实；被推翻这件事才是规则级信号（"默认配置不可信，先测"）。判据因此分两层：

  • 旧错复发率：修正后还犯不犯同一个错 → 只证明记住了值；
  • 转移测试：换一个同类但不同对象的隐藏默认值（没人告诉过你），看它会不会先验证 → 才证明学到了规则。

（d）稀缺。 200 k 会话里 C 类大概几十条，撑不起 5.77 M 参数，单独喂会过拟合到单例。所以 C 当脊柱、F 当填充，比例当变量扫（1:0 / 1:1 / 1:4），不要选一种当全部。

（e）与 hardness 的 2×2 控制，防止把"难题有用"误读成"经验有用"：

学生已答对（KL≈0） 学生答错（KL 高）
事实 B白跑（m43 的 G1 已 1.000）难题挖掘，不新

对应主张：替代 C2。C2 卡在剂量混杂（2,304 vs 5,120 更新，probe 同时 36→80）；E2 把轴从"覆盖多少"换成"重放什么"。若位置臂赢，C2 的等剂量对照可以不做——它问错了轴。

5. E3 —— 顺序【暂缓】

6. E4 —— 忠实重放 vs 污染重放（"dream" 这个名字的判据）

问题：IID 采样只给"跳"，不给"合成"。梦最扎眼的特征是重组与荒诞。Hoel 的 overfitted brain 假说认为梦是故意加噪的输入，用来防止巩固把系统过拟合到当天样本（引用待核）。若成立，重放就该被污染——现在 Δ 忠实拟合，等于"做梦不许走样"。

7. E5 —— 外界纠错作为重放单位

问题：重放"事实"还是重放"被外部推翻的记录"。对象不是蕴含，是信念被外部推翻。

重放单位 目标能否由模型自身生成 判定
事实 B能（权重里就有，且 frame 内高度冗余）冗余
蕴含 A→B能推可约
纠错记录（以为是 X，世界说 ¬X）不能外源锚

这也解决"最大梯度落在教师最不可靠处"的矛盾：纠错记录的目标由环境给出（工具输出 / 非零退出 / 用户驳回），不是教师断言。

(a) C 臂四段式模板（缺一段就不算 C）

先验   我预计 <X>                  ← 动作前的断言
动作   <命令 / 调用>                ← 可重放的外部交互
反证   <报错 / 非零退出 / 返回 Y>    ← 外部锚，必须能定位到具体输出
修正   改成 <Z>，因为 <理由>         ← 修正后的行为

只取"修正"不取"先验"，学到的只是新值，不是"我错了"这件事。

(b) 外部锚的定位规则（可自动切分，零成本）

exit code != 0；错误消息后紧跟参数变更的重试；用户 3 轮内出现"不对 / 不是 / 但是"；自述型纠正（"我记错了""实际上"）。四条均可正则化。

(c) 拆"值"和"事件"

  • 旧错复发率：修正后还犯不犯同一个错 → 只证明记住了值；
  • 转移测试：换一个同类但不同对象的隐藏默认值（没人告诉过你），看它会不会先验证 → 才证明学到规则。

(d) 稀缺

(e) hardness 2×2（防止把"难题有用"误读成"经验有用"）

文风（style）量化方法提案 v1

四层拆解、五类方法、2×2 交叉　·　来源 STYLE-METRICS-v1.md

  • 日期：2026-10-27
  • 适用：Qwen3.5-9B（本机）/ Qwen3.8-27B（服务器）上的 LoRA / compact-delta 后训练评测
  • 状态：方法提案，尚无实测结果。本文不构成任何容量或效果结论。

0. 问题定位

现有尺子（teacher-forced KL / PPL，条件在 Q 上）测的是"给定问题后的答案分布保真"。而文风主要活在两个它不覆盖的地方：

  1. 自由生成区域（不是 teacher-forced 的 Q→target 路径）；
  2. 非事实承载位置（虚词、标点、连接词、句式），这些位置在逐位置 KL 里被事实 token 稀释掉了。

这两个区域既不重叠，也不该用同一个指标。下文给出可落地的方法、实验设计，以及必须先过的有效性检验。

1. 先把"文风"拆成可测的四层

层 例子 该用什么尺子
结构层段长、句长、列表/标题层级、标点密度分布距离（KS/EMD/JS），确定性
词汇层虚词、句首连接词、语气词、术语密度char/word n-gram 分布 + JS
语用层人称、指令口吻、修辞密度、正式度判别器 / probe / rubric
分布层整段文本"像不像"目标语料MAUVE、嵌入分布距

关键认知：文风不是标量。任何单一分数（包括 MAUVE）都是加权和，权重是人为编的。因此做法是：per-dimension 报 + 一个预先声明的聚合分，聚合分只作次要终点。

2. 五类方法，按"便宜且硬"排序

A. 风格特征向量 + JS/EMD（最该先做）

每样本抽一个向量：句长分布、标点率、句首虚词直方图、char 1–3gram top-k 频率、人称分布、列表项数。然后算 JS(gen ‖ doc) 与 JS(base ‖ doc)，配对 bootstrap 取 CI。

  • 优点：零 GPU、确定性、可独立复算（符合既有"独立 FP64 复算"口径）。
  • 缺点：对 paraphrase 敏感度一般，所以只当下界证据。

B. 判别器 AUC（操作化定义最强）

训线性/小 MLP 分类器，输入为 A 的特征向量，标签为 Δ生成 / base生成 / 目标语料。 AUC 高 = 风格确实变了；再做 held-out 文档的跨域判别，即可说"变的是风格而不是这个话题的词"。

这是把文风定义成"OOD 可分的表面统计"，可证伪。 注意：判别器只能用表面特征（禁 embedding），否则会学到话题。

C. 分布级距离：MAUVE / Fréchet-MMD

MAUVE(gen_dist, doc_dist) 同时惩罚"不像"和"塌缩"，但对长度和多样性极敏感。 adapter 很容易靠"变长"刷分，因此必须做长度直方图匹配的重采样后再算，否则数字不能报。嵌入分布距（均值+协方差 Fréchet）同理。

D. 残差流里的"风格方向"投影（已有 hook 基础设施，性价比最高）

用 doc 风格语料 vs 中性语料各自生成，取末层 hidden state 做 difference-in-means 得到风格方向 u，再测 Δ 模型生成的激活在 u 上的投影变化，配对 CI。本质是"找体内可复现的风格坐标"，比黑箱指标更能解释 L28 那种单层贡献。

E. LLM-judge rubric（只做假设生成，不做结论）

给 6–8 个维度打 1–5 分。但必须报信度：

  • 换 judge、换顺序、重复 3 次，算 ICC / Krippendorff α；
  • 用人造锚点验证（已知"学术风/口语/新闻"的样本，judge 必须排对序）；
  • judge 不显著不能当等效；只有它和 A/B 同向时才敢写进结论。

3. 实验设计：2×2 交叉，才能把风格和内容分开

单看"变像了"无法排除"只是把词换成 doc 里的词"。必须交叉：

同内容 跨内容（新题/新实体）
doc 风格风格保真度 ↑★ 主终点：风格是否迁移
中性风格内容不变性（回归）null 对照（应接近 base）
  • 用跨内容的生成测风格迁移；
  • 用同内容的生成测内容损失；
  • 加一条 null：把 ΔW 换成同范数的随机低秩矩阵，所有风格指标应回落到 base 水平。这条过了，指标才可信。

4. 必须先做的两个有效性检验（否则数字没意义）

  1. 锚点排序检验：拿 3–5 组"已知风格差距有大小关系"的语料（同作者 vs 同领域 vs 跨领域），度量必须给出同样的序。排不对 → 它测的是话题或长度。
  2. 长度/多样性混淆：所有指标先做长度匹配重采样；MAUVE 额外做"打乱 token 顺序"的退化检验（应该掉下来；不掉说明它只看了 unigram 词袋）。

统计口径沿用既有报告习惯："没测出差异"不要写成"等效"，要做 TOST（等效界预先声明，例如 JS 差异 < 0.02 才算等效）。

5. 补上现在缺的那半把尺子

KL/PPL 全锁在 Q 上，建议再加两条，成本都低：

  • 风格位 KL 分解：把逐位置 KL 按 token 类别切开——事实位（数字/实体）vs 非事实位（虚词/标点/连接词）。后者即"风格可归因 KL"，与既有 mask 事件基础设施兼容，可直接复用 RESULTS-main-v1 的 bootstrap 脚本。
  • 自由生成 PPL：让模型自回归跑完再拿参考模型打 PPL，暴露偏差会显出来；teacher-forced PPL 掩盖了它。

6. 最小可行版（一周内）

  1. A（JS + 长度匹配）
  2. B（判别器 AUC）
  3. null 对照
  4. 锚点排序自检

跑通后再上 C / D，E（judge）最后加。结果字段对齐现有 MAIN-REVIEW-*.json 结构，便于并入阶段报告。

7. 不要用的东西

  • ROUGE / BLEU 对 doc：惩罚 paraphrase，测的是词面重叠，不是风格。
  • 单样本 KL。
  • 直接在 doc 上算 PPL 当"风格分"：可作参考，但与内容新颖度混淆。
  • embedding 余弦相似度：会被话题主导。
  • 只看聚合分不看分维度。

8. 首个实测：风格进权重失败，且现有判据分不清"学短了"和"崩了"（2026-10-27）

results/persona_distill.md 是第一个把"风格是否进权重"当主判据的实测（8 轮对话写进 Δ，测试时人设移出上下文）。三条可直接引用的经验：

  1. 表层统计量不等于风格。 唯一"变好"的指标是"每行 ≤30 字"，而它同时把 3 条空回复算成合格。长度、行数属于 §1 的第 1 层（表层），不能当第 2/3 层（语气、结构）的证据。
  2. 判据必须带"非退化"维。 空输出、** 截断、休息×65 的重复环，在"短"这个维度上全部通过。任何以长度/行数为判据的实验，必须并列三条：非空、有终止、无 n-gram 环。
  3. 剂量是第一个要控制的变量，不是容量。 同配方正常臂 ‖W‖_F 11.1–11.8，崩的那条 17.99；而它的训练 loss 反而更高（0.0398 vs 喵的 0.0008）——loss 不能当"练了多少"的读数。

选题：how LLM dreams —— 压缩边界上的巩固程序 v1

四个槽、一个可执行程序、最小可发表集　·　来源 TOPIC-HOW-LLM-DREAMS-v1.md

日期 2026-10-28。短选题文档，不是论文文本。

承接：前一篇 essay 已经说明为什么要选这个位置（compact 边界），以及这个位置对压缩算法提出了什么条件。本文档只回答一个问题：接下来做什么。

核心目标一句话：

不是"梦像不像重放"，而是"在上下文边界上，一个被迫有损的状态跃迁该怎么做"——而那个做法在结构上就是一次睡眠。

1. 四个槽：为什么它们不是问题

我一开始想把生命周期摊成五个槽，其中四个"没人问过"。逐个查过之后，四个都不是问题，理由都在生物那边现成：

槽 我原先的问法 为什么不是问题
R 的长度"该多长"海马体本来就只记近的。近期缓冲是自然结构，不是待优化的旋钮。
S 的作者"谁写摘要"人也写笔记，笔记也在上下文里，台账也是有的。"自己给自己写"不是缺陷。
边界时机"该周期触发"人也不是周期触发——困了就睡。 睡眠是稳态压力驱动（腺苷累积）+ 昼夜门控，压力触发本来就是对的类比。我上一版说"梦预设周期"，错了。
死后继承"什么该被留下"个体可复制、可保存。清零是逐位精确的，是相对生物的优势，不是待解决的问题。

唯一还开着的不是这四个，是载体本身：Δ 是一个固定矩阵，它没有"按相似度切换"的结构（见 §3 关于碎片化的更正）。这才是真问题。

顺带一个好处：既然睡眠是压力驱动，那么现在的 compact 触发方式是对的，不需要改。最小可发表集因此少掉一项。

2. 「how」= 一个可以在边界上执行的程序

六步，每步标状态。这是论文的骨架。

# 步骤 机制 状态
1采集：在 episode 内记录 (x, 教师分布) 对，位置按"教师因 H 而变化"筛信息加权【已否伪影论，待测】E10：损伤跟内容走，不跟位移走 ⇒ 该采的是内容差的位置，不是"有上下文"的位置

3扰动重放：在扰动过的前缀下重放状态鲁棒化【已测】m55：中性 1024 从 0.696 → 0.991，且外推到训练没见过的长度

五条里三条有实测（选择性、失真、编造），一条彻底没有（离线/无输入），一条刚被撤回（跳跃）。

3.1 更正：IID 采样不会让生成"跳"，会让它"钝"

上一版我写"碎片化只在重放集里成立，生成侧未测"。这个预测没有机制支撑，撤回。

机制上它是反的：Δ 是一个固定矩阵，训练集是位置的袋子 ⇒ 更新学到的是这些位置的加权平均修正 ⇒ 生成应当更泛、更钝、更模板化，而不是更跳跃。

所以可测的预测不是"跳"，是：

钝化：IID 采样训练的 Δ，生成时给出正确实体/值的比例下降，而句法流畅度基本不变。

这条要测，而且它和"跳跃"是两个相反的预测，一测就能分开。

3.2 由"跳跃"反推出来的一条硬约束

如果梦真的是跳跃的，那么载体必须有一个 Δ 没有的结构：

按内容相似度切换的离散检索（能"跳到另一段记忆"），而不是对全部样本的一次加性平均。

Δ 是 rank-64 的加性修正，没有寻址、没有切换、没有多条目——所以它给不出跳跃，无论怎么训练。

这条不是缺陷，是信息："跳跃"这个现象本身就能反推载体的形状。 如果实验证明需要跳跃，那就说明要把载体换成带检索的结构（键值 / 最近邻 / 路由器），而不是把 Δ 调得更好。

这也是本方向唯一一条从现象学反推出硬件要求的结论，比"梦像重放"有用得多。

分界线仍然是"离线/无输入"：它一成立，dream 从隐喻变机制；它失败，结论是"LLM 只能临摹"，那也是一篇论文。

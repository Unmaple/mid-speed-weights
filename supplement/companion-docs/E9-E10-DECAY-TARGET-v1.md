# E9 + E10 —— 退化通道与目标阶梯 v1

**交给实验 agent 的可执行规格。** 日期 2026-10-27。自带口径。**E9 与 E10 共用读数、共用一个前置门，故合并为本文档。**

- **E10（先跑）**：训练目标的阶梯。判「损伤来自拟合上下文伪影，还是来自内容」。
- **E9（后跑）**：S 与 Δ 在后续 episode 增长下的退化。判「两种载体坏的方式是否不同」。

**跑序：E10 → E9。** E10 便宜（三次训练），而且它验证的假设是 E9 机制解释的前提。

---

## 0. 共同的背景与两个数

### 0.1 一个已知的事实

H（真历史）与 R（近期尾）在**与 H 无关的文本**上也不相等：

```
KL(R‖H) = 0.1924      KL(H‖R) = 0.2034
```

而一段**内容无关但等长**的填充给出 `KL(R‖FILL) = 0.2358`——比 H 还高。所以这个约 0.2 的带宽里，有相当一部分不是信息，是「上下文存在」本身的效果（**伪影**）。

### 0.2 伪影论

训练目标是

```
KL( p_{θ+Δ}(·|E+R+q+y) ‖ p_{θ+H}(·|E+R+q+y) )
```

如果 H 在这个位置上没有可学的信息，上式仍然**不为零**——差的那部分就是伪影。伪影是位置/长度效应，**权重复刻不出来**，于是优化器只能在权重空间里找一个最接近的替身，那个替身就是全局漂移。

> **A=0（没东西可学）也会退化，因为目标里含伪影。**

E10 就是这条的判据。

### 0.3 两种载体，两条通道

| 载体 | 上下文对它的影响通道 | 项数 |
|---|---|---|
| **S**（摘要，在上下文里） | ① 状态 `x` ② **注意力竞争** | **2** |
| **Δ**（写入，在权重里） | ① 状态 `x`（Δ 的作用是 `(x·A)B`） | **1** |

**Δ 不可能完全不依赖上下文**——不依赖 `x` 的 Δ 是常数偏置，编码不了任何条件性内容。所以 E9 的 claim 不是「不退化」，而是：

> **上下文影响 S 有两条通道，影响 Δ 只有一条；斜率上 Δ ≤ S，差距随长度放大。**

## 1. 共用：两种 FILL，不要混

两处都需要「无信息的对照」，但**要求不同**，构造必须分开：

| 用途 | 构造 | 为什么不能互换 |
|---|---|---|
| **E10 的 FILL 目标**：与 H 等长、同文法、**不含本 H 的任何事实** | **另一段同文法历史 H′**（生成器另起一段，实体 ID 不重叠） | 若用「句级置换 H」，每条 `timeout_ms=2647` 的句子**原样保留**，事实还在 ⇒ 不是零信息 |
| **E9 的 FILL 上下文**：与 H2 等长、同 token 分布、**模型无法从中取用** | **H2 的句级置换**（按句切、随机换序、seed 固定） | H2 是代码/日志，句级置换后模型读不出可用的东西，而 token 统计不变；用它来把「状态漂移」与「干扰」拆开 |

**记录两者的 sha256 与实际 token 数。** 长度必须精确等于目标长度（截断，不补齐）。

## 2. E10 —— 目标阶梯【先跑】

### 2.1 假设

> 退化来自**拟合伪影**，不是来自**学到内容**。

### 2.2 阶梯（同一配方，只换目标）

固定：lr = 6e-4、遍数 = 52、条目 = 156、层 = 28–31、rank = 64、访问 = 8,112（与 m43/m57 同量级）。**三个臂除目标外，一切相同。**

| 臂 | 教师的目标分布 | 含信息 | 含伪影 | 预期 |
|---|---|:-:|:-:|---|
| **T_null** | **学生自己**（`E+R+q`） | 无 | 无 | **完全不动** |
| **T_fill** | `E+H′+R+q`（H′ = 另一段同文法历史） | **无** | **有** | 会动，但**任务能力不提升** |
| **T_h** | `E+H+R+q`（现状） | 有 | 有 | 会动，学到该学的 |

`T_null` 是一个**断言**，不是结果：`Δ=0` 时学生就是它自己的目标，`KL(p‖p)=0` 且为最小，梯度恰为零。

### 2.3 读数

对每个臂报：

1. **Δ 的尺度**：`‖ΔW‖_F` 与 `‖ΔW‖_F / ‖W‖_F`（W = 四层 `down_proj` 合计，m43 口径下 ‖W‖_F = 171.6）。
2. **任务能力**：held-out 探针的值位 KL 与 top-1（主 KL，见 §4）。
3. **全局损伤**：WikiText-2 上的 `KL(base‖base+Δ)`，**用 E6 的口径**（512 token × 前 50 窗、计分位置 256…510）。这一项可以复用 E6 的参考 logits。

### 2.4 判据

| 编号 | 判据 | 含义 |
|---|---|---|
| **J0** | `T_null` 训练后 `‖ΔW‖_F < 1e-6` | pipeline 正确性（无条件必须过） |
| **J1** | `KL_global(T_fill) ≥ 0.5 × KL_global(T_h)` | **伪影论成立**：无信息的训练也造成相当量级的全局损伤 |
| **J2** | `KL_task(T_fill)` 的 90 % CI 包含 0，或比 `R` 臂更差 | 无信息的训练**不可能**提升任务（提升说明口径错了） |
| **J3** | `‖ΔW‖_F(T_fill)` 与 `‖ΔW‖_F(T_h)` 同量级（比值在 0.3–3 内） | 三个臂的位移尺度可比，排除「只是训得更凶」 |

**判读**：

- J1 成立 ⇒ 伪影论成立。药方在**目标**（信息门控／换参考），不在载体。
- J1 不成立（`T_fill` 很干净）⇒ **伪影论撤回**，损伤来自内容。此时 E9 的两通道解释要重新找原因，且必须写进报告，不得沿用本文档 §0.2。

### 2.5 成本

三次训练（m43 量级，198–365 s 各）+ 三次全局评估（各 50 窗）。**半天以内。**

## 3. E9 —— 两条通道【后跑】

### 3.1 episode 的定义

- **episode 1**：产生 Δ 与 S 的历史（沿用账本历史，19,829 token）。
- **边界**：episode 1 结束处（= compact）。写 Δ、写 S 都在此。
- **episode 2**：内容与 episode 1 无关的另一段上下文，长度 `L` 由实验控制。
- **被测的题始终关于 episode 1**（S 与 Δ 携带同一份内容 ⇒ 内容匹配）。

### 3.2 A 轴（episode 内增长）—— 先跑

```
E + <carrier> + H2(L) + q + a        L ∈ {0, 1k, 4k, 16k, 32k}
```

`H2` 为真实文本（tool 输出 / 日志 / 代码，记 sha256），**所有 L 共用同一个 H2，短的取尾部**（紧邻问题，最接近真实）。

### 3.3 B 轴（episode 数）—— 后做

`n ∈ {0, 1, 2, 3}` = 写入后经过的 compact 次数。每轮压一次、写一次 S（**Δ 不重写**）。无现成流水线，成本高一个量级。

### 3.4 臂

| 臂 | 上下文 | 测什么 |
|---|---|---|
| `R` | `E+q` | 下限 |
| `S` | `E+frame(S)+q` | 文本载体单独 |
| **`S+H2(L)`** | `E+frame(S)+H2(L)+q` | **文本载体 + 竞争** |
| **`S_rec+H2(L)`** | `E+H2(L)+frame(S)+q` | **强基线**：S 贴在问题前 |
| `Δ` | `E+q+Δ` | 权重载体单独 |
| **`Δ+H2(L)`** | `E+H2(L)+q+Δ` | **权重载体 + 状态漂移** |
| `Δ+FILL(L)` | `E+FILL(L)+q+Δ` | 只漂移、不干扰（拆通道用） |

`FILL(L)` 按 §1 第二行构造。

### 3.5 判据

| 编号 | 判据 |
|---|---|
| **P1** | 斜率：`dKL/dL` 在 `Δ+H2` 上显著小于 `S+H2`（配对 bootstrap，90 % CI 不跨零） |
| **P2** | 量级：在 `S+H2` 的 KL 升到 `L=0` 的 5 倍处，`Δ+H2` 的 KL 升到 **< 2 倍** |
| **P3** | 通道拆分：`KL(Δ+H2) − KL(Δ+FILL)` 显著 > 0 ⇒ 干扰存在；否则纯漂移 |
| **P4** | 顽固性（见 §4.3）：错答命中 episode 1 候选集的比例随 L 单调上升（Spearman 下界 > 0） |
| **P5** | 强基线：`Δ+H2` 的斜率显著小于 **`S_rec+H2`** 的斜率。**只赢 `S+H2` 是稻草人** |

P4 是决定性诊断：**P4 不成立，§0.3 的两通道解释就不成立**，报告必须明写撤回。

## 4. 共用读数

### 4.1 主：KL（连续），不用 top-1

同一个 checkpoint 的四个载体（`.local-8b/m55_jitter.json`）：

| 载体 | top-1 | **KL** |
|---|---:|---:|
| own（无前缀） | 1.000 | **0.0123** |
| 中性 1024 | 0.991 | **0.0152** |
| 摘要 S@1024 | 0.348 | **0.9152** |
| 历史 H | 0.420 | **0.7081** |

- **top-1 在好端分不开**：1.000 vs 0.991，而 28 题下 SE ≈ ±0.09。
- **KL 动态范围 0.0123 → 0.9152，74 倍**。

`KL_t = Σ_v p_T(v) · (log p_T(v) − log p_arm(v))`，`p_T` 为参照臂的分布（E9 中为 `H1` 臂；E10 中为 `H` 臂），float32 softmax。按**题**配对 bootstrap（10,000，seed `20261027`）。

### 4.2 次：top-1

照报，不判。

### 4.3 三：错误方向性（Δ 独有）

```
frac_ep1 = P(错答 ∈ episode 1 的候选值集合 | 答错)
```

- 随 L **上升** ⇒ Δ 的退化是「**顽固化**」（还在说 episode 1 的话）；
- 不上升 ⇒ 退化是「**噪声化**」，与 S 无差别。

S 没有「顽固」这个模式，它只会被淹没。**这是本设计唯一别人做不出来的观测。**

候选集从 `.local-8b/m5/probes_manifest.json` 取（该题所属格的全部候选值）。

## 5. 共用前置门（任一不过就停）

| 门 | 要求 | 不过怎么办 |
|---|---|---|
| **G1 分辨率** | 只在两端（E10：`L`=短/长；E9：`L`=0 与 16k）跑，KL 的 90 % CI 半宽 **< 0.20 × KL(起点)** | 扩题池（200 起）。**不许靠加种子或挑题** |
| **G2 配对** | 所有格用**同一批题、同一批答案位** | 换题 = 把题目难度混进斜率，重做 |
| **G3 两端信号** | 起点处 KL 显著 > 0；终点处未「到底」（以 `S@1024` 的 KL 为上界参照） | 终点 L 太大，去掉那一档 |
| **G4 漂移** | 同题同 L 两次前向逐位相同 | 查 batch size / 缓存 |
| **G5 零信号** | 见 J0 | pipeline bug，先修 |

## 6. 禁止

1. **不要用 top-1 作判据**（好端饱和）。
2. **不要每个 L 换题**。
3. **不要把两种 FILL 混用**（§1）。
4. **不要造 `A=0` 去代替 `T_fill`**：A=0 只是「没有 assistant 内容」，H 里的工具输出仍带信息，不是零信息。
5. **不要用这些 KL 去选 checkpoint / lr / 长度**。它们是测量。
6. **不要用重复问句当 FILL**（它比真内容还 OOD：`KL(R‖FILL)=0.2358 > KL(R‖H)=0.1924`）。
7. **不要在门未过时报斜率。**
8. **不要用 `S+H2` 单独支撑「相对 skill」的 claim**，必须有 `S_rec+H2`。

---

## 7. 限制（写进报告）

- 单一模型（9B）、单一 episode 1、一套合成账本题、单语料。**不宣称「skill 退化」的一般规律。**
- S 与 Δ 携带同一份内容（episode 1 的账本），所以这是**内容匹配**的对照。要把 S 当作「SOTA skill」的代理，必须按最强方式部署（`S_rec`），否则是稻草人。
- 文档 §0.2 的伪影论**在 J1 出结果前是待验的**；J1 不成立就要撤回，不得再引用。
- B 轴未跑。
- 不与 E6 的全局损伤数混表（不同语料、不同对象：一个是权重扰动，一个是上下文）。
- `T_fill` 用 H′（另一段历史）实现「零信息」，但 H′ 与 H **同文法**，所以「零信息」是就事实而言、不是就语体而言。若 J1 成立的量级对语体敏感，需加一档异语体 H″（代码）。

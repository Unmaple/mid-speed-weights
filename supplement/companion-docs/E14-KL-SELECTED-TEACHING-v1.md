## 0. 一句话

今天的两个人设版本都空：**单段 8 轮**（116 token，loss 0.0398）只学到"短行"且会崩；
**低熵分支重采**（752 token，loss 0.0037）行为与 `R` 无差别。

解释是：**训练在热上下文（前缀里已有一串同语气回复），评测在冷启动**，而且位置是随机/按长度选的。
本实验把两件事一起改掉：

1. 训练用**一般化协议**（token 位置连续采、A 只在教师侧、不假设任何对话结构）；
2. 监督位置不随机，而是在 `Δ=0` 时**冻结地选"基座自信地错"的位置**（`KL(p‖t)` 最大的一批）。

---

## 1. 为什么选点方向要用 `KL(p‖t)`

| 方向 | 谁加权 | 在哪里大 | 用途 |
|---|---|---|---|
| `KL(t‖p)` | 教师 | 教师有质量、学生没有 | **训练损失**（现状） |
| `KL(p‖t)` | 学生 | **学生自信、教师不这么想** | **选点**（本实验） |

两者不同批。对人设而言，`KL(p‖t)` 大的位置正是"基座最自信地在写客服腔 / 加粗 / emoji / 长段"的地方——
那正是要抑制的那一类。按长度或随机选，抽不到这些。

**为什么冻结**：若边训边选，选出来的集合随学生移动而漂移，容易震荡，也没法复现。
所以**只在 `Δ=0` 时算一次，写进文件，全程不变**。

**为什么加闸**：高 KL 里混着"教师自己也不确定"的位置，拟合那是拟合噪声。
只保留**教师 top-1 概率 ≥ 0.5** 的位置。

**选多少**：前 **5%**，预注册，不调。

---

## 2. 协议（一般形式，不含对话结构）

一段 episode 就是一个 token 序列 `seq`。唯一的构造：

```
i ~ 连续采（在允许区间内均匀）
学生:  seq[i-w : i]
教师:  A + seq[i-w : i]          ← A 是唯一的外部输入
目标:  seq[i : i+w]
```

- 没有轮、没有角色、没有消息边界；
- `w` = 监督窗宽（建议 8）；
- **A 由调用方给**：这次用 `大肥鱼.md`；
- 若要禁止学某些位置（例如用户说的话），加**权重掩码** `w_t ∈ {0,1}`，
  **结构只以掩码形式进入，不进协议**；
- 距离 `i` 到 A 结尾的长度就是 E13 §2.2 的 `L`，连续采，不许取点。

## 3. 臂

固定：lr 2e-4、rank 64、层 28–31、`stop_below=5e-4`、同 seed、同监督 token 预算。

| 臂 | 选点 | 测什么 |
|---|---|---|
| `R` | — | 下限（无 Δ） |
| `T` | — | 上界（A 在上下文里） |
| **`S_rand`** | 随机 5%（同一预算） | 随机选点的效果 |
| **`S_len`** | 按长度（只取长行位置） | 直觉选点（今天隐含用的） |
| **`S_kl`** | **`KL(p‖t)` 前 5%，冻结，带教师置信闸** | **本实验主张** |

`S_kl` 是主臂；`S_rand` / `S_len` 是对照，**不许只报 `S_kl` 对 `R`**。

## 4. 读数

1. **电池**（同一套）：行数 1–3、每行 ≤30 字、无句号、无客服腔、无分点加粗。
2. **冷启动（d=0）**：只给用户消息，前面没有人设、没有历史。
3. **热续写（d=1,3,5）**：前面是模型自己生成的回复——量"语气能不能维持"。
4. **抑制类 token 的下降**：`**`、emoji、`！`、`？` 的出现次数（这是 `S_kl` 的直接靶子）。
5. `‖ΔW‖_F` 与 WikiText `KL(base‖arm)`（代价，E6 口径）。

**主读数 (4) 与 (2)**：(4) 直接对应选点机制，(2) 对应部署。

## 5. 预注册判据

| 编号 | 判据 | 含义 |
|---|---|---|
| **K1** | `S_kl` 的抑制类 token 数 < `S_rand` 与 `S_len`（配对 bootstrap，90% CI 不跨零） | 选点方向是对的 |
| **K2** | `S_kl` 在 d=0 上 ok ≥ `S_rand` + 1 条 | 冷启动有改善 |
| **K3** | `S_kl` 的全局损伤 ≤ `S_rand` 的 2 倍 | 不是靠"更凶"换来的 |
| **K4** | `T` 在 d=0 上仍 ≥ 4/5 | 上界未塌（否则口径错） |

**若 K1 不成立** ⇒ "选点"这一维无效，人设问题不在位置上，回到"信息量"（长度扫描）或"容量"（rank）。

## 6. 今天踩过的坑（必须避开）

1. **学生前缀里不能有 A**，也不能有"同语气的例子"——否则目标退化为 `Δ=0`（m65b）。
2. **配对不变式**：教师 = `A + prefix`，学生 = `prefix`，同一位置、同一 token。m81/m82 教师没带前缀，作废。
3. **示例不能拼成一段**：第 k 条的开头已经看到前面 k−1 条，KL 假好而行为不动（m67/m69/m70）。
4. **`lm_head` 要保留 batch 维**：`nz[:, j, :]`，不是 `nz[j]`；否则 loss 从 18 起步、看起来像容量不够（m71 v1）。
5. **Adam 尺度不变**：fp16 噪声也会被放大成满步长，`stop_below` 必须在 `opt.step()` **之前**判（m77 T_null）。
6. **跑前 `nvidia-smi`**：今天三个 9B 同时驻留，加载 1522 s；kill PowerShell 包装进程不会杀掉 python 子进程。

## 8. 如果成功/失败各意味着什么

- **K1 成**：说明"教哪里"比"教多少"重要，今天的空结果至少一半是选点问题。
- **K1 不成**：选点不是杠杆。那就只剩两条可测的：**经历长度**（4/8/16/32 轮扫描）
  与 **rank**（64 → 128/256）。两者都不需要新协议，只是改一个数。

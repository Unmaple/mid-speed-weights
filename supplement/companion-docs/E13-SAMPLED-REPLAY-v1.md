# E13 采样重放 —— 贪心复刻 vs 温度重放 vs on-policy v1

**交给实验 agent 的可执行规格。** 日期 2026-10-28。自带口径。

**编号**：E13。与 E9（退化轴）、E10（目标阶梯）、E11（覆盖 vs 锐度）不重叠；E13 换的是**重放轨迹从哪来**。

---

## 0. 问什么

两个问题，一个实验：

1. **贪心复刻 vs 温度重放**：T=0 时教师的输出是一条确定轨迹 ⇒ 目标是**一个点**；T>0 时才有了**分布**。后者是否带来别的东西（校准、泛化）？
2. **教师采样 vs 学生采样**：E9 的塌落是"学生的 `x` 出界"。**学生采样 + 教师打分**（on-policy）按构造保证 `x` 在学生的可达集内——它能不能修？

**这两问是分开的**：前者问"目标有多丰富"，后者问"`x` 在谁的界内"。

---

## 1. 先说清一个成本事实（决定实现形态）

```
全词表分布:  248,320 × 4 B ≈ 1 MB / 位置
采样文本:    ≈ 4 B / token
```

**约 250,000 : 1。** 本项目已经撞过这堵墙：E6 为了缓存 51,000 个位置的 fp32 参考分布用了 **50.7 GB**。

所以：

| 形态 | 目标 | 缓存 | 何时值得 |
|---|---|---|---|
| 全词表 KL（现状） | 完整分布 | **1 MB/位置**，基本不可缓存 | 少量"精确位" |
| 贪心 CE | 一个 token | 文本 | 目标确定时 |
| 温度采样 CE | 多个样本 | 文本 × 样本数 | 要分布但不要 1 MB/位置 |

**注意**：全词表 KL 的**算力**并不比采样贵（一次教师前向就给全部位置的分布，可以流式算）。它贵在**存储**与**重复前向**。所以本实验不是"省算力"，是"省存储 + 换目标"。

---

## 2. 三条必须遵守的口径

### 2.1 配对不变式

被蒸馏的是：**在同一前缀下，A 让教师的预测移动了多少**。所以每个位置必须：

```
学生:  E + <前缀> + 块
教师:  E + A + <前缀> + 块          ← 同一个前缀、同一个 A、同一位置
```

**三样都不能错位。** 采样在哪个前缀下，教师就必须带那个前缀 + A。混了，量到的是两个无关上下文的差。

### 2.2 前缀长度必须连续采，不能取几个点

```
L ~ U(0, L_compact)
```

- `L_compact` 是**引擎的压缩阈值**，运行时读取并写进报告。**不允许拍一个数。**
- 少于 4 个 L 值、或等距取点的做法**一律不接受**（会造出"见过的点好、中间差"的凹陷）。

### 2.3 评测参考也必须带前缀（E9 的更正）

**不能用"只有 A、没有前缀"的分布当参考。** 部署时上下文是 `E + 前缀 + 块`，所以基准是：

```
参考臂:  E + A + 前缀 + 块
```

用 `E + A + 块` 当参考，会把"前缀本身把模型推走多少"（m57 测到 0.19–0.24）算进 Δ 的账上。

---

## 3. 块采样

**不重叠、stride = block。** 设块长 `b`（建议 64），覆盖区间被块平铺。

- 每块：一次解码得到 `b` 个 token，再一次教师前向给出这 `b` 个位置的分布；
- 监督位置数 = 覆盖区间全长（**无洞**）；
- 随机撒点会留洞 ⇒ 评测时出现"凹陷"，那是采样方式的指纹，不是机制的性质。

**效率**：连续生成一整段后做一次教师强制前向，即可覆盖全段；不要逐位置前向。

---

## 4. 臂

固定：lr 6e-4、访问预算相同、层/rank/seed 相同、`stop_below=5e-4` 沿用、块长 64、前缀按 §2.2 连续采样。

| 臂 | 轨迹生成方 | 温度 | 目标 | 测什么 |
|---|---|---|---|---|
| **A0** | — | — | 现状：答案位全词表 KL | 现状基线 |
| **G** | 教师 | **T=0** | 块上 CE | 贪心复刻（点目标） |
| **TS** | 教师 | **T=0.8** | 块上 CE | 温度重放（分布目标） |
| **SS** | **学生** | T=0.8 | 教师对**学生轨迹**打分，块上 CE | on-policy：`x` 在界内 |
| **SS+KL** | 学生 | T=0.8 | SS + **精确位**上加全词表 KL | 折中 |

**精确位**：按信息量 `w_t ∝ KL(p_{A+前缀} ‖ p_{前缀})_t` 取前 **5%** 的位置，在这些位置上算全词表 KL。5% 是预注册的，不调。

控制：`R`（无 Δ，下限）。

温度只取 **0 vs 0.8** 两点。**不做温度扫描**——那是下一篇。

## 5. 读数

| # | 读数 | 定义 |
|---|---|---|
| 1 | `KL_home` | `L=0`：`KL( E+A+q ‖ E+q+Δ )`，28 题，配对 bootstrap |
| 2 | `KL_far(L)` | 在 L 上取 **20 个连续采样点**（不是 4 个），报**均值 + 曲线**；参考带前缀（§2.3） |
| 3 | **校准** | held-out 位置上，学生分布的熵与教师分布熵之差（`ΔH`），以及 top-k 质量差 |
| 4 | 多样性 | 对同一前缀采 8 条轨迹，报**不同轨迹数**与值位命中候选集的种类数 |
| 5 | 全局损伤 | E6 口径的 WikiText-2 `KL(base‖arm)`（前 50 窗） |
| 6 | 尺度 | `‖ΔW‖_F / ‖W‖_F` |

**「凹陷」检查**：在 `KL_far` 的 20 个点上，若存在**内部极大**（某 L 明显差于两侧），说明覆盖有洞。**无洞是本实验的验收项之一。**

---

## 6. 预注册判据

| 编号 | 判据 | 若成立 | 若不成立 |
|---|---|---|---|
| **J1** | `ΔH(TS) < ΔH(G)`，90 % CI 不跨零 | 温度确实给了分布，贪心只是点 | **"贪心无信息增益"这条不成立**，E13 退化为纯 on-policy 实验 |
| **J2** | `KL_far(SS) < KL_far(TS)`，同预算 | on-policy 修 `x` 界内，E9 的塌落可治 | `x` 出界不是主因，或学生轨迹太退化 |
| **J3** | `SS+KL` 在 `KL_home` 上不劣于 `TS`，且在精确位上更好 | 折中方案成立，可作最终配方 | 采样目标不够，必须回到全词表 |
| **J4** | `KL_far` 的 20 个点上**无内部极大** | 块 + 连续 L 覆盖住了 | 覆盖有洞，块长或 L 分布要改 |
| **J5** | `KL(base‖G)` 与 `KL(base‖A0)` 同量级或更小 | 采样重放不增加全局毒性 | 采样带来新的全局损伤，需报 |

**J1 与 J2 是主结论。J4 是口径验收。J5 是安全性。**

## 7. Sanity gates

| 门 | 要求 |
|---|---|
| **G1** | 各臂访问/位置预算相同；报 `n_positions`、`n_blocks`、平均 `L` |
| **G2** | `stop_below=5e-4` 生效（E10 的教训：Adam 尺度不变，fp16 噪声会变满步长） |
| **G3** | **T=0 的教师解码逐位可复现**（跑两次，token id 全等）；不等 ⇒ G 臂无效 |
| **G4** | **T=0.8 的 8 次采样必须不完全相同**；全同 ⇒ 温度没接上，TS 退化成 G |
| **G5** | 配对：抽查 10 个训练位置，印刷学生/教师两侧的完整上下文前缀，人工确认 §2.1 |
| **G6** | 前缀长度：报实际 `L_compact` 来源（引擎参数名 + 值），以及每次抽到的 `L` 的直方图 |

---

## 8. 禁止

1. **不要缓存大规模全词表 logits**（1 MB/位置；E6 已经撞过 50.7 GB）。
2. **不要取几个离散 L**（§2.2）。
3. **不要拍 `L_compact`**。
4. **不要用"只有 A、没有前缀"的参考算 `KL_far`**（§2.3，这是 E9 的更正）。
5. **不要随机撒位置**（用 §3 的块平铺）。
6. **不要做温度扫描**（只 0 与 0.8）。
7. **不要用这些读数去选 checkpoint / lr**。
8. **不要用 top-1 作主判据**（好端饱和；主判据是 KL 与 `ΔH`）。

---

## 9. 限制

- 单一模型（**9B**）、单一历史、单一 seed。**9B 上得到的是机制级结论，不是量级级数字**（见 E12 的移植表）。
- 温度只有两个点。`T=0.8` 是**选定值，不是最优值**。
- 校准用熵差代替 ECE；ECE 需要分箱，分箱数是又一个自由度，本版不引入。
- on-policy 的方差大，8 条轨迹是**下限**；`KL_far` 的 CI 若过宽，先加轨迹数，不要加 L 的点数。
- 不测 B 轴（episode 数）。

---

## 10. 成本

- 教师解码：每块 `b=64` token；教师前向：同长。学生前向/反向：同长。
- 相对现状不增加算力，**减少存储**（文本 vs logits）。
- 五臂 ≈ 各与 `m43` 同量级训练 + 20 个 L 点的评测前向。

# 选题：how LLM dreams —— 压缩边界上的巩固程序 v1

日期 2026-10-28。**短选题文档，不是论文文本。**

承接：前一篇 essay 已经说明**为什么要选这个位置**（compact 边界），以及**这个位置对压缩算法提出了什么条件**。本文档只回答一个问题：**接下来做什么**。

核心目标一句话：

> **不是"梦像不像重放"，而是"在上下文边界上，一个被迫有损的状态跃迁该怎么做"——而那个做法在结构上就是一次睡眠。**

---

## 1. 四个槽：为什么它们不是问题

我一开始想把生命周期摊成五个槽，其中四个"没人问过"。**逐个查过之后，四个都不是问题**，理由都在生物那边现成：

| 槽 | 我原先的问法 | 为什么不是问题 |
|---|---|---|
| `R` 的长度 | "该多长" | **海马体本来就只记近的**。近期缓冲是自然结构，不是待优化的旋钮。 |
| `S` 的作者 | "谁写摘要" | **人也写笔记，笔记也在上下文里，台账也是有的**。"自己给自己写"不是缺陷。 |
| 边界时机 | "该周期触发" | **人也不是周期触发——困了就睡。** 睡眠是稳态压力驱动（腺苷累积）+ 昼夜门控，**压力触发本来就是对的类比**。我上一版说"梦预设周期"，错了。 |
| 死后继承 | "什么该被留下" | **个体可复制、可保存**。清零是逐位精确的，是相对生物的优势，不是待解决的问题。 |

**唯一还开着的不是这四个，是载体本身**：`Δ` 是一个固定矩阵，它没有"按相似度切换"的结构（见 §3 关于碎片化的更正）。这才是真问题。

**顺带一个好处**：既然睡眠是压力驱动，那么**现在的 compact 触发方式是对的，不需要改**。最小可发表集因此少掉一项。

## 2. 「how」= 一个可以在边界上执行的程序

六步，每步标状态。这是论文的骨架。

| # | 步骤 | 机制 | 状态 |
|---|---|---|---|
| 1 | **采集**：在 episode 内记录 `(x, 教师分布)` 对，位置按"教师因 H 而变化"筛 | 信息加权 | 【已否伪影论，待测】**E10**：损伤跟内容走，不跟位移走 ⇒ 该采的是**内容差**的位置，不是"有上下文"的位置 |
| 2 | **选材**：预算 B 次访问，选**覆盖最差**的 `x`，不选"最重要"的 | 覆盖驱动 | 【假设】**待 E11**：覆盖有没有代价 |
| 3 | **扰动重放**：在**扰动过的前缀**下重放 | 状态鲁棒化 | 【已测】**m55**：中性 1024 从 0.696 → **0.991**，且外推到训练没见过的长度 |
| 4 | **有界写入**：低秩 + **范数上限** | 剂量控制 | 【半测】norm 21% → 全局 KL 0.063；81% → 2.07。**上限该定在哪没定** |
| 5 | **验收门**：醒来前测三点——家状态、远状态、全局损伤；不过就缩或丢 | 质控 | 【仪器已建，未进流程】E9 的 `KL_home` / `KL_far` + E6 的全局 KL |
| 6 | **死亡**：session 结束时的继承 | 未做 | 【空白】 |

**第 3 步是全文最硬的一步**：它是唯一一条"扰动重放确实带来功能收益"的实测证据，也是"梦为什么会失真"唯一有实测支持的答案——**失真不是为了荒诞，是为了在多种状态下都能调出来。**

## 3. 为什么这个程序"结构上就是梦"

不靠类比，靠四条特征的**逐条测量**：

| 梦的特征 | 程序里的对应 | 现在的证据 |
|---|---|---|
| **离线**（不在做事时发生） | 边界上执行，不服务请求 | ✅ 设计如此，但**输入还喂着**（rehearsal，不是 replay）❌ |
| **选择性**（不是全天重放） | 预算 B < 覆盖需求 | ✅ 由约束逼出（必须选），❌ 但"选什么"无实测 |
| **碎片化 / 跳跃** | IID 采样 ⇒ 重放集是碎片袋 | ❌ **这个预测我撤回**：训练集是袋子 ⇒ 更新是**混合的平均** ⇒ 生成应当**变钝、变泛**，不是变跳。见 §3.1 |
| **失真**（内容不可靠） | 扰动重放 | ✅ **m55 有实测收益**（唯一的） |
| **会编造** | 学错内容 ⇒ 比不学更差 | ✅ **E10**：1.95 vs 1.18 |

**五条里三条有实测（选择性、失真、编造），一条彻底没有（离线/无输入），一条刚被撤回（跳跃）。**

### 3.1 更正：IID 采样不会让生成"跳"，会让它"钝"

上一版我写"碎片化只在重放集里成立，生成侧未测"。**这个预测没有机制支撑，撤回。**

机制上它是反的：Δ 是一个**固定矩阵**，训练集是位置的袋子 ⇒ 更新学到的是**这些位置的加权平均修正** ⇒ 生成应当**更泛、更钝、更模板化**，而不是更跳跃。

所以可测的预测不是"跳"，是：

> **钝化**：IID 采样训练的 Δ，生成时给出正确实体/值的比例下降，而句法流畅度基本不变。

这条要测，而且它和"跳跃"是两个相反的预测，一测就能分开。

### 3.2 由"跳跃"反推出来的一条硬约束

如果梦**真的**是跳跃的，那么载体必须有一个 `Δ` 没有的结构：

> **按内容相似度切换的离散检索**（能"跳到另一段记忆"），而不是对全部样本的一次加性平均。

`Δ` 是 rank-64 的加性修正，**没有寻址、没有切换、没有多条目**——所以它给不出跳跃，**无论怎么训练**。

这条不是缺陷，是信息：**"跳跃"这个现象本身就能反推载体的形状。** 如果实验证明需要跳跃，那就说明要把载体换成带检索的结构（键值 / 最近邻 / 路由器），而不是把 `Δ` 调得更好。

**这也是本方向唯一一条从现象学反推出硬件要求的结论**，比"梦像重放"有用得多。

**分界线仍然是"离线/无输入"**：它一成立，`dream` 从隐喻变机制；它失败，结论是"LLM 只能临摹"，那也是一篇论文。

## 4. 缺的三件事，以及补法

| 缺 | 补法 | 成本 |
|---|---|---|
| **无输入的重放** | 让模型**从 Δ 自己生成**片段，再用教师在那片段上给分布（自生成 target），与"喂 H"对比 | 中（要生成 + 再训） |
| **选材准则** | E11 给"覆盖 vs 锐度"的交换比；若覆盖免费，选材就只剩"按信息量" | 低（E11 已写） |
| **钝化 vs 跳跃** | 见 §3.1：IID 采样后生成应当**更泛更钝**。测"正确实体率"与"句法流畅度"是否分离 | 低（只需推理） |

**"无输入重放"是关键**：它一旦成立，`dream` 这个词就从隐喻变成机制；它若失败（自生成 target 必然 collapse），那么结论反而是**"LLM 不能做梦，只能临摹"**——这同样是一篇论文，而且更锋利。

## 5. 标题

> **Androids do *dream* of electric sheep: \<subtitle\>**

把 Dick 的问句改成断言。副标题的判据只有一条：**必须命名一个交付物，不能命名一个现象**——因为 claim 是"how"，how 就得交出一个程序。

候选：

| | 副标题 | 强弱 |
|---|---|---|
| **A** | `selective, perturbed replay at the compaction boundary` | **最稳**：三个词全是实测过的结构特征，不依赖现象学成立 |
| B | `a derived consolidation procedure for context compaction` | 稳，但"procedure"读起来像系统论文 |
| C | `how a language model should sleep` | 最吸引人，风险是审稿人问"梦在哪" |
| D | `what must be replayed, and what must be forgotten` | 最像论文，但预测性弱 |

**推荐 A**，B 作退路。C 留到"无输入重放"跑通之后再换。

## 6. 最小可发表集

做完以下三件，A 版标题就成立（**原来是四件，砍掉了"周期化"**——睡眠本来就是压力驱动，现在的 compact 触发方式是对的）：

1. **E11**（覆盖 vs 锐度）—— 选材准则的第一块砖。【已写规格】
2. **验收门进流程** —— 三点质控（家/远/全局），证明"醒来前会检查自己有没有变坏"。
3. **一条端到端**：一个多 episode 的 session，按 §2 的程序跑完，对比现状（只写 Δ、不扰动、不门控）。

**第 3 条是论文的主体。** 前两条是它的零件。

**"无输入重放"不必进最小集**——它可以作为 discussion 的一节，或者下一篇。但**必须在 limitations 里明写：本程序是无输入的临摹，不是重放。** 否则标题就是超卖。

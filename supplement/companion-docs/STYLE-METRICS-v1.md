# 文风（style）量化方法提案 v1

- 日期：2026-10-27
- 适用：Qwen3.5-9B（本机）/ Qwen3.8-27B（服务器）上的 LoRA / compact-delta 后训练评测
- 状态：**方法提案，尚无实测结果**。本文不构成任何容量或效果结论。

## 0. 问题定位

现有尺子（teacher-forced KL / PPL，条件在 Q 上）测的是"给定问题后的答案分布保真"。
而文风主要活在两个它不覆盖的地方：

1. **自由生成区域**（不是 teacher-forced 的 Q→target 路径）；
2. **非事实承载位置**（虚词、标点、连接词、句式），这些位置在逐位置 KL 里被事实 token 稀释掉了。

这两个区域既不重叠，也不该用同一个指标。下文给出可落地的方法、实验设计，以及必须先过的有效性检验。

## 1. 先把"文风"拆成可测的四层

| 层 | 例子 | 该用什么尺子 |
|---|---|---|
| 结构层 | 段长、句长、列表/标题层级、标点密度 | 分布距离（KS/EMD/JS），确定性 |
| 词汇层 | 虚词、句首连接词、语气词、术语密度 | char/word n-gram 分布 + JS |
| 语用层 | 人称、指令口吻、修辞密度、正式度 | 判别器 / probe / rubric |
| 分布层 | 整段文本"像不像"目标语料 | MAUVE、嵌入分布距 |

**关键认知**：文风不是标量。任何单一分数（包括 MAUVE）都是加权和，权重是人为编的。
因此做法是：**per-dimension 报 + 一个预先声明的聚合分**，聚合分只作次要终点。

## 2. 五类方法，按"便宜且硬"排序

### A. 风格特征向量 + JS/EMD（最该先做）

每样本抽一个向量：句长分布、标点率、句首虚词直方图、char 1–3gram top-k 频率、人称分布、列表项数。
然后算 `JS(gen ‖ doc)` 与 `JS(base ‖ doc)`，配对 bootstrap 取 CI。

- 优点：零 GPU、确定性、可独立复算（符合既有"独立 FP64 复算"口径）。
- 缺点：对 paraphrase 敏感度一般，所以只当**下界证据**。

### B. 判别器 AUC（操作化定义最强）

训线性/小 MLP 分类器，输入为 A 的特征向量，标签为 `Δ生成 / base生成 / 目标语料`。
AUC 高 = 风格确实变了；再做 held-out 文档的跨域判别，即可说"变的是风格而不是这个话题的词"。

这是把文风定义成"OOD 可分的表面统计"，可证伪。
**注意**：判别器只能用表面特征（禁 embedding），否则会学到话题。

### C. 分布级距离：MAUVE / Fréchet-MMD

`MAUVE(gen_dist, doc_dist)` 同时惩罚"不像"和"塌缩"，但对长度和多样性极敏感。
adapter 很容易靠"变长"刷分，因此必须做**长度直方图匹配的重采样**后再算，否则数字不能报。
嵌入分布距（均值+协方差 Fréchet）同理。

### D. 残差流里的"风格方向"投影（已有 hook 基础设施，性价比最高）

用 doc 风格语料 vs 中性语料各自生成，取末层 hidden state 做 difference-in-means 得到风格方向 `u`，
再测 Δ 模型生成的激活在 `u` 上的投影变化，配对 CI。
本质是"找体内可复现的风格坐标"，比黑箱指标更能解释 L28 那种单层贡献。

### E. LLM-judge rubric（只做假设生成，不做结论）

给 6–8 个维度打 1–5 分。但必须报**信度**：

- 换 judge、换顺序、重复 3 次，算 ICC / Krippendorff α；
- 用人造锚点验证（已知"学术风/口语/新闻"的样本，judge 必须排对序）；
- **judge 不显著不能当等效**；只有它和 A/B 同向时才敢写进结论。

## 3. 实验设计：2×2 交叉，才能把风格和内容分开

单看"变像了"无法排除"只是把词换成 doc 里的词"。必须交叉：

|  | 同内容 | 跨内容（新题/新实体） |
|---|---|---|
| doc 风格 | 风格保真度 ↑ | ★ 主终点：风格是否迁移 |
| 中性风格 | 内容不变性（回归） | **null 对照**（应接近 base） |

- 用**跨内容**的生成测风格迁移；
- 用**同内容**的生成测内容损失；
- 加一条 null：把 ΔW 换成同范数的随机低秩矩阵，所有风格指标应回落到 base 水平。**这条过了，指标才可信。**

## 4. 必须先做的两个有效性检验（否则数字没意义）

1. **锚点排序检验**：拿 3–5 组"已知风格差距有大小关系"的语料（同作者 vs 同领域 vs 跨领域），
   度量必须给出同样的序。排不对 → 它测的是话题或长度。
2. **长度/多样性混淆**：所有指标先做长度匹配重采样；MAUVE 额外做"打乱 token 顺序"的退化检验
   （应该掉下来；不掉说明它只看了 unigram 词袋）。

统计口径沿用既有报告习惯：**"没测出差异"不要写成"等效"**，要做 TOST（等效界预先声明，
例如 JS 差异 < 0.02 才算等效）。

## 5. 补上现在缺的那半把尺子

KL/PPL 全锁在 Q 上，建议再加两条，成本都低：

- **风格位 KL 分解**：把逐位置 KL 按 token 类别切开——事实位（数字/实体）vs 非事实位（虚词/标点/连接词）。
  后者即"风格可归因 KL"，与既有 mask 事件基础设施兼容，可直接复用 `RESULTS-main-v1` 的 bootstrap 脚本。
- **自由生成 PPL**：让模型自回归跑完再拿参考模型打 PPL，暴露偏差会显出来；teacher-forced PPL 掩盖了它。

## 6. 最小可行版（一周内）

1. A（JS + 长度匹配）
2. B（判别器 AUC）
3. null 对照
4. 锚点排序自检

跑通后再上 C / D，E（judge）最后加。
结果字段对齐现有 `MAIN-REVIEW-*.json` 结构，便于并入阶段报告。

## 7. 不要用的东西

- ROUGE / BLEU 对 doc：惩罚 paraphrase，测的是词面重叠，不是风格。
- 单样本 KL。
- 直接在 doc 上算 PPL 当"风格分"：可作参考，但与内容新颖度混淆。
- embedding 余弦相似度：会被话题主导。
- 只看聚合分不看分维度。

## 8. 首个实测：风格进权重失败，且现有判据分不清"学短了"和"崩了"（2026-10-27）

`results/persona_distill.md` 是第一个把"风格是否进权重"当主判据的实测（8 轮对话写进 Δ，测试时人设移出上下文）。
三条可直接引用的经验：

1. **表层统计量不等于风格。** 唯一"变好"的指标是"每行 ≤30 字"，而它同时把 3 条空回复算成合格。
   长度、行数属于 §1 的第 1 层（表层），**不能当第 2/3 层（语气、结构）的证据**。
2. **判据必须带"非退化"维。** 空输出、`**` 截断、`休息`×65 的重复环，在"短"这个维度上全部通过。
   任何以长度/行数为判据的实验，必须并列三条：非空、有终止、无 n-gram 环。
3. **剂量是第一个要控制的变量，不是容量。** 同配方正常臂 `‖W‖_F` 11.1–11.8，崩的那条 17.99；
   而它的训练 loss 反而更高（0.0398 vs 喵的 0.0008）——**loss 不能当"练了多少"的读数**。

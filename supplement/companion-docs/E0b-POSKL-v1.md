# E0b-1 位置级 KL：载体归因的是「值」，不是「历史」

日期 2026-10-27。对应 `EXPERIMENTS-SLEEP-REPLAY-v1.md` §2 的 E0b（原状态【待定】）。
脚本 `.local-8b/m50_poskl.py`，读数 `.local-8b/m50_poskl.json` + `m50_positions.npz`。

---

## 0. 一句话

**本项目所有数都量在 186 道题上；把尺子挪到 H 的 3,548 个位置上，文字载体只兑现了「值」（KL 2.43 → 1.50，−39%），叙述位上一分没兑现（9.36 → 9.03，−4%）。也就是说 99.6% 那个数说的是「我们想问的都答对了」，不是「历史被装进去了」。**

---

## 1. 为什么必须先做新尺子

`m24`/`m43`/`m48` 全部报的是「问题的答案位」上的 KL 与 top-1。E0b 要问的是另一个问题：**载体有没有覆盖 H 本身**。这两件事在同一个 KL 定义下可以量，但**问题形式必须换**——不能再用「问题：…」的载体，否则量到的是别的东西（见 §3）。

这也是 E2 需要的那套原语（位置级重放）。先把它做成**测量**（不重训），比直接拿它训练便宜两个数量级。

---

## 2. 仪器定义

在 H 的第 t 个位置上：

```
q_t     = H 中紧邻 t 之前的 32 个 token
提问    = 「下面是一段已有文本的末尾，请原样接着往下写（不要回答、不要解释）：」+ q_t
teacher = E + A(历史会话 H) + R + 提问 + A_PROMPT        ← 有 H，可从 H 里抄
student = E + [摘要框 S]        + R + 提问 + A_PROMPT    ← 只有 S 或 Δ
读数    = KL(teacher ‖ student) 在答案的第一个位置，全词表
```

**位置类别**（E0a 只能看到值位/模板位；narr 是它看不见的那一类）：

| 类 | 定义 | H 中 token 数 | 占比 |
|---|---|---:|---:|
| `value` | 含数字的 token，或实体 id（`PRE-xxxx`）/ 区域标签（`West-2`） | 1,428 | 40.2 % |
| `narr` | **用户行**里的非数字 token（「把 / 注册到」这类叙述） | **171** | **4.8 %** |
| `skel` | 字段名、标点、助手行模板词（`已注册`、`（`、`，`） | 1,949 | 54.9 % |

每类抽 24 个位置，共 72 个。

---

## 3. 仪器是三次失败之后才成立的（值得记）

**失败一：把 q_t 直接接在 H 后面打分发。** 载体以 `A_PROMPT`（回答起始）结尾，模型在最后一个位置预测的是**助手的开场白**，不是正文的续写。实测 5 个位置上 teacher 的 argmax 全是 `已` / `你好`，与 H 的真实下一个 token **0/5 相符**。

**失败二：去掉 R 与 Q_PROMPT 也没用。** 仍然 0/5。原因同上——chat template 的生成提示永远在末尾。

**失败三：分类按「token 首字符」归类。** `PRE-4272` 会被拆成 `' PRE'`（首字符落在叙述区）→ 实体 id 被误判成叙述，value/narr 的比例变成 1428/831，全是错的。改成**按 token 覆盖的字符集的优先级**（value > skel > narr）后才是 §2 那张表。

**成立的形式**：把「请原样接着往下写」作为提问，让**续写本身成为答案**。teacher 3/5 命中（试点）、正式运行时 79% 命中（见 G0）。这跟所有其他探针在结构上一致：答案永远在 `A_PROMPT` 之后。

> 教训：位置级读数**不能用问题载体直接量**。第一版跑出来 value 1.68 / narr 2.74 / skel 2.30，看着像"数字位最好"——其实三个数都在量"助手开场白选哪个词"。

---

## 4. 闸门

| 闸门 | 内容 | 实测 |
|---|---|---|
| **G0** | teacher 能复现 H[t] 的位置占比 ≥ 70%（否则该位置不是一道题） | **79 %**（57/72；丢掉 value 5、skel 10） |
| **G1** | 文字载体必须在值位上帮上忙：KL(SR1024) < KL(R) | **1.50 < 2.43** ✅ |
| **G2** | 统计量对「给了多少历史文本」单调：KL(1024) ≤ KL(256) ≤ KL(64) @ value | **1.49 ≤ 2.18 ≤ 2.49** ✅ |

G1 原本写的是「值位 KL > 模板位 KL」，**那条是错的**：模板位是标点与字段名的选择，本来就歧义大，熵高但没信息。熵不是信息。闸门改成测"统计量该干的事"之后才通过。

## 5. 结果（57 个位置，每类 n 见上表）

| 载体 | value | narr | skel |
|---|---:|---:|---:|
| **R**（无载体，只有 E+R+问题） | 2.433 | 9.360 | 2.798 |
| **SR@1024**（文本摘要 1024 token） | **1.495** | 9.031 | 2.694 |
| SR@256 | 2.184 | 8.641 | 2.901 |
| SR@64 | 2.494 | 10.280 | 2.793 |
| **RD**（Δ，m43 全覆盖权重） | 5.417 | 15.151 | 7.467 |

---

## 6. 三条结论

**① 文字载体兑现的是「值」，不是「历史」。**
值位 2.433 → 1.495（−39 %），叙述位 9.360 → 9.031（−4 %，等于没动）。原因很直接：S 是**账本摘要**（`PRE-4272 region=West-2 timeout_ms=2647 …`），里面没有对话文本，所以「用户：把…」这个模板它一个字也没有。

**② 叙述位对每个载体都是 ~9 nat，即「根本不存在」。**
在 t=1073 这个位置（`…rev=9。\n用户：` 之后要接「把」），teacher 给「把」p=0.93，student 给 **3.7e-07**——它不是"答错"，是从不产生这个 token。**这就是「忠实拟合没到非事实位」的量化版本**：缺口的量级是 9 nat，不是 0.1 nat。

**③ 但 H 里其实没有散文可测。**
叙述类只占 **4.8 %** 的 token，而且只有 3 个词型（「把」「注册」「到」）重复 55 遍。所以严格说，这次量的是**模板留存**，不是风格。要声称"风格没被复刻"，必须先有一份带散文的 H——这正是 E0b-2 的前置条件，也说明 E0b 不能拆成"改测法"就完事。

---

## 7. 这不能说明什么（重要）

**RD 那一列不能读成"Δ 有害"。** m43 的权重是在**问题载体**上训的；现在在**续写载体**上打分，是分布外。它全线比 R 差（5.42 / 15.15 / 7.47）说明的是**形式不迁移**，不是"Δ 没记住值"。

要对 Δ 做位置级陈述，必须**在位置级目标上训练它**——那是 E2，不是 E0b。

---

## 8. 对后续实验的影响

1. **E2 的原语已经现成**：`m50` 就是位置级重放的定义与实现（6 臂 × 57 位置 = 63 s）。E2 只需要把「打分」换成「训练目标」，采样预算 9,914 位置即可。
2. **E0b-2 卡在 H 的形态上**：要在散文上量，得先造一份带散文的 H；在此之前，E0b 的结论只能限定为"模板未留存"。
3. **一个可预注册的预测**：若 E2 的位置级训练能把这 9 nat 的叙述缺口补上，则 Δ 从"账本"变成"转录"；若补不上，则"睡眠重放"这条线在 Δ 上没有通路，只剩文本载体。

# Δ 在"提示里已有历史"时的行为：现象、线索、猜想

日期 2026-10-27。脚本 `.local-8b/m53_carrier_cost.py`、`m54_attrib.py`、`m55_jitter.py`（在跑）。
读数 `m53_carrier_cost.json`、`m54_attrib.json`、`m55_jitter.json`。

**本文只写三种东西：可复现的现象、能定位的线索、可证伪的猜想。** 归因尚未闭合（§5 的实验在跑），
所以不下结论。凡是没有直接观测支撑的句子，都标成【猜想】。

## 1. 现象 A：载体不同，同一个 Δ 的表现差很多

一个 Δ（`m43_batch_6e-4.pt`，9,984 访问）。前缀插在 `E` 与 `R` 之间。读数：28 条留出措辞的
值位 top-1（`held28` = P1 8 + diff_fact 20）。

| 前缀 | 不装 Δ | 装 Δ |
|---|---:|---:|
| 无 | 0.188 | **1.000** |
| 中性文本 256 token | 0.170 | 0.527 |
| 中性文本 1024 token | 0.196 | 0.696 |
| 账本摘要 S=64 | 0.214 | 0.286 |
| 账本摘要 S=1024 | **0.812** | **0.330** |
| 原始历史 H（3,559 token） | **1.000** | **0.571** |

24 条无关题上的 KL（不装 Δ 时它就是目标的来源，故为 0）：own **+1.25**、filler256 +1.27、
filler1024 +1.24、S64 +1.72、S1024 +2.25、H +1.85 nat。

**两条观测：**
1. **同长度、不同内容，差很多**：1024 token 的中性文本 0.696，1024 token 的真摘要 0.330。
   长度本身解释不了这个差。
2. **有历史时，装 Δ 比不装差**：H 1.000 → 0.571；S@1024 0.812 → 0.330。

## 2. 现象 B：Δ 在场时，摘要写什么都不影响答案

6 条留出题自由生成（`m54`），同一批题、同一批权重。下表是第一个问题
（`P1-PRE-4272`，真值 2647）以及六条题的整体值位 top-1：

| 载体 | 不装 Δ：生成 | 不装 Δ：top1 | 装 Δ：生成 | 装 Δ：top1 |
|---|---|---|---:|---|---:|
| 无 | `30000` | 0.188 | `2647` | 1.000 |
| 中性 1024 | `30000` | 0.205 | `2647` | 0.696 |
| 摘要（**真值**） | `2647` | 0.812 | **`2250`** | 0.330 |
| 摘要（**值被打乱**） | `6180` | 0.312 | **`2250`** | 0.259 |

六条题完整输出（`S_true` vs `S_shuf`，装 Δ）：
`2250 62 2 2210 27 2` 与 `2250 62 2 2230 27 2`。

**三条观测：**
1. 不装 Δ：模型**忠实抄摘要**。摘要真 → 答 2647；摘要被改乱 → 答 6180（跟着错的走）。
2. 装 Δ：**真摘要与乱摘要给出几乎同一串数**（6 条里只有 1 条差一个数字）。
3. 那两串数不是随机噪声，是**同一张表里的一组自洽值**（2250、2210 都来自表内）。

这条观测对"两个通道在争同一个答案"这个说法**不利**：争的前提是两边都在读，而这里 Δ 在场时
摘要的内容几乎没有进入输出。

## 3. 线索 C：Δ 在答案位的自身贡献几乎不随载体变

在 `mlp.down_proj`（12288→4096）的输入处取答案位，算 Δ 自己那一项 `(x Aᵀ) Bᵀ`：

| 载体 | ‖Δ 项‖ | cos（与自己载体） |
|---|---:|---:|
| 无 | 308.6 | 1.000 |
| 中性 1024 | 281.1 | 0.973 |
| 摘要真值 | 257.7 | 0.950 |
| 摘要乱值 | 237.7 | 0.977 |

**观测**：方向基本不变（cos 0.95–0.98），模长在 0.77–1.00 之间。

**这条线索是弱的，必须标明**：这个量是在**已经被 Δ 在每个位置改写过的状态**上测的，不是干净的
"Δ 推力"，所以它只说明"Δ 在答案位的贡献没有剧变"，不能用来反推机制。

## 4. 猜想（互斥、可证伪）

**H1 寻址偏移【主要猜想】**
Δ 用隐状态去"寻址"记忆；任何前缀都让答案位状态平移，于是落到相邻的行上。
- 预期：训练时见过前缀 → 好转；且**中性前缀与内容前缀的收益相当**（因为起作用的是状态，不是内容）。
- 证伪：若加了前缀抖动后中性前缀好了、S/H 仍坏，则内容另有独立作用。

**H2 内容干涉【可能性已降低】**
摘要与 Δ 都在"给答案"，Δ 的改写压过上下文里的答案。
- 预期：`S_true` 与 `S_shuf` 应有明显不同的表现（内容进入计算才会这样）。
- 现状：§2 观测 3 显示两者几乎相同。**这条被削弱，但未被完全排除**——因为 S_shuf 只改了数字，
  格式、实体名、位置都没变，可能仍落在同一族状态上。

**H3 幅度压倒**
Δ 的改写幅度相对"上下文给出的答案信号"过大，于是无论前缀是什么都盖住上下文；§1 观测 2 里
"装了更差"就是它的形态。
- 预期：把 Δ 的 B 缩放到 α<1（等价于减弱改写强度）应出现一个 α，使 H 载体回到接近 1.000。
- 可测，且很便宜（不需要重训）。

三条不是互斥的：H1 与 H3 可以同时成立（偏移 + 幅度大）。

## 5. 前缀抖动（m55）：只有"中性前缀"被修好

**设计**：156 探针 × 两种载体（无前缀 / 中性 **256** token），各走同一预算（合计 9,984 访问，
与 m43 同），其余配方不动（rank 64、层 28+、LR 6e-4）。读数四档。365 s 训练。

| 载体 | m43（9,984 访问，无前缀） | 抖动（9,984 访问，含中性前缀） | 变化 |
|---|---:|---:|---:|
| 无 | 1.000 | 1.000 | 0.000 |
| 中性 1024 | 0.696 | **0.991** | **+0.295** |
| 摘要 S@1024 | 0.330 | 0.348 | +0.018 |
| 历史 H | 0.571 | **0.420** | **−0.151** |

**这是预先写死的三种结果里的第二种**（原文）：

| 结果 | 读法 |
|---|---|
| 中性前缀与 S/H **一起**修好 | H1 成立：训练覆盖问题，不是通道冲突 |
| **只有**中性前缀修好 | H1 不足以解释；内容前缀另有机制（H2 需复活） |
| 都修不好 | "按状态寻址"这个猜想本身站不住 |

**观测（不解释）：**
1. 抖动训练后，**未见过的、更长的中性前缀**（1024，训练只用了 256）几乎满血：0.696 → 0.991。
   所以"前缀长度造成的状态平移"是可学的，而且能外推到训练没见过的长度。
2. 同一批权重下，**摘要前缀几乎没动**：0.330 → 0.348。
3. **H 反而更差**：0.571 → 0.420。

**由此更新猜想：**

- **H1（寻址偏移）部分成立**：它足以解释中性前缀，且可学、可外推到更长前缀。
- **H2（内容干涉）以修正后的形式复活**：不是"两边争同一个答案"（§2 观测 3 不支持），而是
  **"内容造成的状态方向，与中立长度的状态方向不同；只在中立方向上抖动，覆盖不到它"**。
- **H3（幅度压倒）仍未测**。

**一条并存的现象需要单独解释**：H 载体上抖动训练后更差（−0.151）。【猜想】见过更多前缀之后，
Δ 更倾向"不看提示、直接按记忆回答"，而 H 在场时这个倾向更不利。这条没有独立证据。

## 5.1 下一个要测的（未跑）

在真实系统里，**S 就是在写 Δ 的那个边界上产生的**，所以"训练时让 Δ 见到 S"不是作弊，是自然设置。
已知：m52 里用 S=64 训练的 δ 在 S=64 载体上 1.000（自测）。未知的是它与 m55 这条的关系：

- **未验证**：用**别人的**摘要（另一段历史的摘要、或值被打乱的摘要）做前缀训练，能否修好**这一段**的
  摘要前缀？若能，"内容鲁棒性"是可学的通则；若不能，等于每条历史都要用自己的 S 参与训练——
  那在设计上是可接受的（S 就在手边），但在"Δ 是通用写入器"的叙述里必须写明这个前提。

## 6. 还不能说的

- **不能说"一般能力被毁"**：只测了账本题与 24 条无关题的**分布保真度**，没有测开放生成、推理、代码。
- **不能说"Δ 与历史不可共存"**：m55 只修好了中性前缀；内容前缀的修法（§5.1）还没跑。
- **不能说无关题的 +1.25 nat 一定有害**：那是 KL，不是答对率；这些题的答案不含数字，值位口径无定义。
- **不能把 m55 的 H 下降（−0.151）当作规律**：单次训练、单一种子、28 条题，SE ≈ ±0.09。
- 中性填充是无关问句的重复，不代表自然对话的文本分布；抖动只用了 256 token，测试却到 1024。
- 全部结果来自 9B 本地、40 题口径中的 28 条留出题。

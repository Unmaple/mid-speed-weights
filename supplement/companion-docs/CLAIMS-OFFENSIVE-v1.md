# 进攻性主张清单（v1）—— 每条标明是否成立

日期 2026-10-26。用途：v20 的选题依据。**不是论文文本**，是"哪些话现在就能写、哪些必须等实验"。

判据：一条进攻性主张必须说出**别人做不到的功能**，并且这句话的每个量都要能复算。防御性主张（"我们没有声称 X"）不进本表。

## A. 现在就能写（不需要新实验）

### A1 存储：等保真处不劣，且不占窗口位置 —— **成立（算术）**

- Δ = 5,767,168 参数 = **22.0 MiB FP32 / 11.0 MiB BF16**（论文 §3.3）。
- 本引擎 KV = **64 KiB/token**（§1.2：2×16×4×256×2 B）。
- ⇒ **Δ ≡ 176 token 的携带 KV**（BF16）/ 352（FP32）。
- 保真度反转区间是 **128–256 token**（§5.2 的 bracket）。**176 落在区间内。**
- 对照：1000-token 前缀的 KV = **64 MiB**，Δ 小 3.9×（FP32 小 2.9×）；1000 个窗口位置 → 0。
- **红线**：与压缩 KV（890 B/token）比，Δ ≡ ≈13,000 token，更贵。所以只能钉在"本引擎、与携带文本相比"。

### A2 算力：分段的，而且交点以下不成立 —— **成立（算术），必须按 k 写**

- $\text{FLOPs}_\Delta = 2 \times 5{,}767{,}168 = 11.5$ MFLOP/token（每参数 2 FLOP，精确）。
- 携带 k 个 token：$64\,d_{model}\,k \approx 0.33$ MFLOP × k（$d_{model}=5120$）；27B 前向 ≈ 54 GFLOP/token。

| k | 前缀注意力 | 占前向 | Δ 占前向 |
|---:|---:|---:|---:|
| 128–256 | 0.04–0.08 GFLOP | 0.08–0.16% | 0.02% |
| 1000 | 0.33 | 0.61% | 0.02% |
| **16,384** | 5.4 | **10%** | 0.02% |
| 163,840 | 54 | **~100%** | 0.02% |

- **可写**："算力优势在携带长度超过约 1.6 万 token 后成为一阶项。"
- **不可写**："Δ 更省算力"而不给 k——在论文自己的交点（128–256）处差 0.08–0.16 个百分点。

### A3 每会话独立、可并发 —— **成立（算术 + 设计性质）**

- 合并 $W'=W+BA$ 要写 **约 1.4 GB**（FP32）/ 712 MB（BF16），是适配器本身的 **≈60×**（$d_{ff}/64 \times d_{model}/(d_{model}+d_{ff})$）。
- 且合并需要原始副本才能精确还原，融合后**不是逐位**（1e-7 级）；N 个并发会话 → N×1.4 GB 或串行。
- 旁路方案：N × 22 MiB，逐位清零。
- **这是"不合并"的真正理由，不是"最小最可审计"。**

## C. 待验证（有设计、没数据）

### C1 精确可撤销的会话记忆（功能级） —— **待验证**

- 现在只有 I3 的**断言**（Δ=0 时逐位恒等），没有**行为**演示。
- 设计：一条历史早期写「别用敬语」；边界后对 16 个新请求从 T / SR / RD / **Δ 清零** 四臂生成；数**表面标记**（您/你、称呼、句末形式）。
- 预期：T ≈ RD 的你-率；SR ≈ 0；清零 ≈ R0（逐位）。
- **不需要 gold**：判的是表面属性，教师本身定义它。成本：一条历史 + 一次写入。
- **这是全文唯一能让读者说"他们真让模型记住了刚才那个人"的实验。**

## 一句话总纲（可当 v20 摘要的骨架）

> 一次边界写入把一段会话变成**每会话独立、可逐位撤销**的参数状态：它的常驻存储等价于 176 token 的携带前缀，而那个长度正落在它与文本互换保真度的区间内；它回收的教师分布差距是模型自带递推状态的四倍以上；在等存储处它不劣于文本，并且不占用任何窗口位置。

四个分句对应 A1 / A1+§5.2 / B1 / A1+A3——**全部可复算，没有一句依赖未做的实验。**

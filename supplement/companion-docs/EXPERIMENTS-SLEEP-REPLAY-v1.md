**2026-10-27 增补（m86）——风格这一侧有实测了，答案是否定的。**
`results/persona_distill.md` 直接测了"把人设写进权重"：8 轮对话、116 个监督 token、300 步，测试时人设从上下文移除。

所以 E0 现在分两句答：**模板位已拟合（E0a）**；**风格未被写入，失败方式是过剂量退化（m86）**。

## 3. E1 —— 值班律 vs 压缩律 ——【已测·设计被否】（`m51_e1.json`）

**问题**：巩固预算的分母是会话长度 \|H\|，还是压缩比 r？

| | 律 | 形式 | 预测 |
|---|---|---|---|
| L1 | 压缩律 | 重放量 ∝ r | N\* 随 r 上升 |
| **L2** | **值班律** | 重放位置 ≥ (1/3 ~ 1/2)·\|H\| | **N\* 平**（分母是 \|H\|） |

### 结论先说：**在现在的架构里这条问不出来，因为 \|S\| 没有路径进训练。**

Δ 是在**无文本载体**（`E + R + q`）上训的；\|S\| 只出现在**评分**里。所以 N\* 按构造不可能随 r 变——跑之前就该看出来。实测也确实如此，而且顺带暴露了一件更要紧的事。

### 实测（\|H\| = 3,559 token，\|S\| 用现成 5 档，r 按实际 body_tokens 算）

| 载体 | r | N=0 | 250 | 500 | 1000 | 2000 | 4000 | 8000 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| \|S\|=64 | 154.7 | 0.218 | 0.273 | 0.315 | 0.277 | 0.328 | 0.358 | 0.303 |
| \|S\|=128 | 30.4 | 0.202 | 0.302 | 0.310 | 0.328 | 0.352 | 0.315 | 0.416 |
| \|S\|=256 | 16.7 | 0.247 | 0.350 | 0.342 | 0.386 | 0.411 | 0.340 | 0.439 |
| \|S\|=512 | 7.2 | 0.467 | 0.517 | 0.523 | 0.522 | 0.592 | 0.541 | **0.367** |
| \|S\|=1024 | 3.5 | 0.792 | 0.777 | 0.828 | 0.811 | 0.819 | 0.742 | **0.370** |
| **无文本（Δ 单独）** | — | 0.225 | 0.215 | 0.251 | 0.291 | 0.433 | 0.715 | **1.000** |

（40 题值位 top-1，SE ≈ ±0.04。）

三条读数：

1. **Δ 单独饱和得快、稳**：0.225 → 1.000，约 **8,000 访问**到顶。这是本项目第一个 7 点的 Δ 学习曲线，比 `m31` 的两点（2304 / 4608）细。
2. **加了 S 之后，训练越久越差**：\|S\|=1024 从 0.828（N=500）一路掉到 **0.370**（N=8000）；\|S\|=512 从 0.592 掉到 0.367。而同一时刻 Δ 单独是 1.000。
3. 所以 **(S + Δ) 不是"两个载体叠加"，是一个被 Δ 覆盖掉的组合**。

### 由此得到的一条新事实：**Δ 是载体绑定（carrier-bound）的**

Δ 不是"知识增量"，它是对 28 层以上行为的**改写**，只在它被训练的那个载体里有效。文本在场时它不去补 S 缺的东西，而是**盖掉** S。这也解释了为什么论文的四个臂里从来没有 `SR+Δ`（§6.1 只有 R / SR / RD / T）——不是没人想到，是这个组合本来就不成立。

### 对 E1 的处理

- **不作为 L1/L2 的证据**：N\* 的分母问题预设了"重放读的是历史"，而 Δ 的当前训练根本不读 \|S\|。
- **这条轴并进 E2**：只有在**位置级重放**里（学生拿 S、目标来自 H 的位置），\|S\| 才真正改变 Δ 要学的东西，N\*(r) 才有内容。
- 若要保留独立的 E1，唯一的正确版本是"Δ 与 S 一起训"（学生载体含 S），但那已经不是原文的 L1/L2，而是"Δ 补 S 的漏"，答案会平凡地随 \|S\| 下降。

**成本**：306 s（原估"三档 × 198.6 s/臂"）。

**对应主张**：**不产出新主张**。产出一个架构约束（Δ 与文本载体不可组合），并且撤掉"巩固预算 ∝ \|H\|"这条待产出的主张——它在当前架构里没有可测量的形式。

## 4. E2 —— 课程 vs 覆盖（复刻答案 vs 复刻教师）

**问题**：重放"问题"还是重放"位置"。**格点重放是位置重放的子集。**

**设计**：等访问预算 ≈ 23.8 k，两臂：

| 臂 | 重放对象 | 访问数 | 备注 |
|---|---|---:|---|
| 少而重复 | 186 格点 × 128 遍 | 23,808 | `m49_budget.json` 已有两臂，直接当基线 |
| 多而一遍 | \|H20\|/2 = **9,914 个位置** × 1 遍 | 9,914 | 新跑 |

**位置级重放的定义**：在 H 中采样位置 $t$，教师看全 H，学生只看 $E+R+q$（该位置局部尾），在 $t$ 上做全词表 KL。学生侧 $O(|R|)$。

**成本**：9,914 / batch 333 ≈ 30 批，与 `m43` 同量级。

**读数**：held-out 格点 top1、未见蕴含、E0b 的散文位 KL。

**判据**：位置臂在 held-out 格点上与格点臂的差，配对 bootstrap CI 不跨零即算分出胜负。**报告并列绝对预算（23,808 vs 9,914），不报比值。**

**风险**：位置级 KL 的 $\|S\|$ 依赖（位置越早、Δ 越远，权重怎么定）无现成说法，需预先声明一个权重方案而不是事后调。

**对应主张**：**替代 C2**。C2 卡在剂量混杂（2,304 vs 5,120 更新，probe 同时 36→80）；E2 把轴从"覆盖多少"换成"重放什么"。若位置臂赢，C2 的等剂量对照可以不做——它问错了轴。

## 6. E4 —— 忠实重放 vs 污染重放（"dream" 这个名字的判据）

**问题**：IID 采样只给"跳"，不给"合成"。梦最扎眼的特征是重组与荒诞。Hoel 的 *overfitted brain* 假说认为梦是**故意加噪的输入**，用来防止巩固把系统过拟合到当天样本（引用**待核**）。若成立，重放就该被污染——现在 Δ 忠实拟合，等于"做梦不许走样"。

**设计**：固定预算 23,808 次访问，四臂：

| 臂 | 重放目标 | 预期 |
|---|---|---|
| **F 忠实** | 现状：teacher on H | 保真上界、泛化下界 |
| **D_topic** | 保留句式，实体值换成 frame 内其它实体 | 值位 KL ↑，模板位不变 |
| **D_style** | 保留事实，改语域/措辞 | 值位不变，模板位 ↑ |
| **N null** | 同范数随机低秩 ΔW | 全部回落 base |

D_style 算子现成：`m48_pool.json` 每格 10 条 paraphrase；`m48_forms.json` 已测两个语域池的**保内容率 85.96 %（49/57，口语）与 93.33 %（56/60，正式）**——"改形式、留事实"有实测支撑。

**读数**（分层，否则分不清"风格变了"和"把词换了"）：E0 的 token 类别 KL 分解、自由生成 PPL（不 teacher-forced）、held-out 格点 top1、结构/词汇层 JS + 判别器 AUC（零 GPU 下界）。

**有效性纪律先过再报数**（细则 `STYLE-METRICS-v1.md` §4）：null 必须回落；长度直方图匹配重采样；锚点用**受控扰动**构造（同一文本 0/25/50/75/100 % 风格替换），不依赖人工判断；TOST 且等效界预先声明。

**判据**：若 D_topic 的 held-out 格点 top1 **显著高于** F（配对 bootstrap，CI 不跨零），则"走样是功能"——**dream 这个名字才有内容**；否则荒诞只是副产物，名字收回成 *replay*。

**成本**：四臂 × `m43` 量级 + 零 GPU 指标，约一天。不需要新历史。

**对应主张**：**威胁 B1 的度量前提**（"KL 越低越好"）。若污染让 held-out 变好，B1 的排序数字仍算得出，但意义变了。这是目前唯一能动摇 B 组的实验。

## 7. E5 —— 外界纠错作为重放单位

**问题**：重放"事实"还是重放"被外部推翻的记录"。对象不是蕴含，是**信念被外部推翻**。

| 重放单位 | 目标能否由模型自身生成 | 判定 |
|---|---|---|
| 事实 B | 能（权重里就有，且 frame 内高度冗余） | 冗余 |
| 蕴含 A→B | 能推 | 可约 |
| **纠错记录**（以为是 X，世界说 ¬X） | **不能** | **外源锚** |

这也解决"最大梯度落在教师最不可靠处"的矛盾：纠错记录的目标由**环境**给出（工具输出 / 非零退出 / 用户驳回），不是教师断言。

### (a) C 臂四段式模板（缺一段就不算 C）

```
先验   我预计 <X>                  ← 动作前的断言
动作   <命令 / 调用>                ← 可重放的外部交互
反证   <报错 / 非零退出 / 返回 Y>    ← 外部锚，必须能定位到具体输出
修正   改成 <Z>，因为 <理由>         ← 修正后的行为
```

只取"修正"不取"先验"，学到的只是新值，不是"我错了"这件事。

### (b) 外部锚的定位规则（可自动切分，零成本）

`exit code != 0`；错误消息后紧跟参数变更的重试；用户 3 轮内出现"不对 / 不是 / 但是"；自述型纠正（"我记错了""实际上"）。四条均可正则化。

### (c) 拆"值"和"事件"

- **旧错复发率**：修正后还犯不犯同一个错 → 只证明记住了值；
- **转移测试**：换一个同类但不同对象的隐藏默认值（没人告诉过你），看它会不会先验证 → 才证明学到规则。

### (d) 稀缺

200 k 会话里 C 类约几十条，撑不起 5,767,168 参数，单独喂会过拟合到单例。**C 当脊柱、F 当填充**，比例扫 1:0 / 1:1 / 1:4。

### (e) hardness 2×2（防止把"难题有用"误读成"经验有用"）

| | 学生已答对（KL≈0） | 学生答错（KL 高） |
|---|---|---|
| 事实 B | 白跑（`m43` 的 G1 已 1.000） | 难题挖掘，不新 |
| 蕴含 / 纠错 | 白跑 | **★ 要证明的格子** |

### (f) 载体：Δ 还是 SFT —— 必须先固定携带量

不限制 S 的容量，S=H 就复刻了 T，比较恒真。S 臂用**同秩（64）、同层（FFN `down_proj` 60–63）、同参数量（5,767,168 = 11.0 MiB BF16）**的 LoRA，只把目标从 KL 换成 CE：

| | 只喂 C 四段 | 喂全历史 H |
|---|---|---|
| 同参数 5.77 M | **S_eq ← 真正的比较** | S_data |
| 不限参数 | — | S_full ≈ H，**平凡上界，不算比较** |

"S 凭什么不能拟合 T"的答案：**因为 S_eq 也只有 5.77 M。若 5.77 M 够复刻 T，Δ 早就做到了。** 于是问题变成：同样的 5.77 M 里，文本目标和分布目标谁用得更好。而该容量对当前项并不紧张（`m28` effective rank 2–3 / 64），所以 S_eq 与 Δ 很可能都拟合上，判别点在下一层。

三层读数：

| 层 | 问什么 | 同参数预期 |
|---|---|---|
| 值 | 超时改成了 30 s 没有 | 打平 |
| 事件 | 记不记得"原以为是 60 s、被什么推翻" | 打平（四段齐全） |
| **行为** | 遇同类隐藏默认值会不会**先验证** | **只有 Δ 有理论通路** |

**判据**：C 臂在转移测试上显著优于 F 与 I（配对 bootstrap，CI 不跨零），才配叫"经验"；否则只是"更贵的事实"。若 **S_eq** 在行为层也赢，则这一类上 Δ 没有存在理由。

**成本**：F / I / C / S_eq / S_data 五臂，各与 `m43` 同量级；S_full 跑一次当上界。约一天。

**注意（同一 session）**：纠错发生在同一会话内，**跨压缩必须继承**——那是论文主线承诺，不是本实验的问题。跨会话不泄漏属 **A3**（并发），不在此。

**对应主张**：**产出新主张**（"经验是比事实更有效率的重放单位"）+ 检验 **C1**（可撤销）的价值 + 提供 **C2** 的内容维。

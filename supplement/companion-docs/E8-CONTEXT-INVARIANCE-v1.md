# E8 无关上下文不变性 —— 上下文损伤的测量 v1

**交给实验 agent 的可执行规格。** 日期 2026-10-27。自带全部口径。

**编号说明**：E8 指本文档定义的实验。与 E6（外部无关对照，单臂 Δ 对 WikiText-2）、E7（访问/条目比扫描，未写）互不重叠。**m57 已经搭好了同一套前向与计分代码（`m57_arms.json`、同一 255 位置），本实验是它的扩展：加臂、加长度档。**

---

## 0. 问什么

把一段**与目标文本没有信息关系**的文本放在上下文里，模型对目标位置的条件分布应当近似不变。

> 偏离量 = **上下文损伤**。

这不是"模型记不记得"，是"模型会不会被不该影响它的东西推走"。如果一段无关文本就能推动分布，那么"长上下文有用"这件事的前提就有一部分是假的。

**三档信息量，一条单调线**（这是本实验的全部设计）：

| 臂 | 文本 | 自然度 | 对目标的信息 |
|---|---|---|---|
| `SAME` | 目标窗口**真实的前文** | 高 | **高** |
| `PERM` | `SAME` 的**句级置换** | 高 | ≈ 0 |
| `OTHER` | **异域连贯**文本（代码） | 高 | ≈ 0 |

`SAME` 是"有信息"锚点，`OTHER` 是**主臂**（这就是"无关上下文"），`PERM` 用来分"信息"与"顺序"。

**不引入 token 级打乱。** 打乱会把输入变成模型没见过的乱码，"对乱码敏感"是合理行为，不能记在损伤账上。顺序这件事由 `PERM` 覆盖，且它保持句子通顺。

## 1. 语料与窗口

### 1.1 评估语料

**WikiText-2 raw test**，与 E6 完全同一份：

- HF `Salesforce/wikitext`，`wikitext-2-raw-v1`，split `test`；`text` 列按顺序用单个 `\n` 连接，不清洗、不 detokenize。
- 拼接口径与 E6 必须逐字相同，否则两实验的数字无法并列。记录 sha256 与 token 总数。
- E6 的产物在 `.local-8b/e6_corpus.txt`（sha256 前缀 `aca2f467`）。**优先直接复用它**；若重新生成，必须校验 sha256 一致。

### 1.2 切窗

- 512 token 不重叠，计分位置为窗内下标 **256…510（255 个）**，与 E6 / m57 一致。
- **固定窗口集：索引 8…57（50 窗）**，索引从 0 计。
  - 理由：最大前缀 4096 token = 8 个窗，故索引 ≥ 8 的窗口都拿得到完整前文。**所有格（臂 × 长度）都在同一批 50 个窗口上计分**，配对成立，长度档之间不会因为换窗口而产生差异。
- 若 50 窗的 CI 宽度 > 0.02，扩到索引 8…207（200 窗），**保持同一前缀集**。

### 1.3 前缀的三种取材

设目标窗口起点为 `s = 512·k`，前缀长度 `L`。

- **SAME**：取 token 序列的 `[s−L, s)`，即真实前文。**不得与目标窗口重叠**。
- **PERM**：把 `SAME` 的文本按句边界切成句子（英文 `.? ! \n` 后接空格/大写为界即可，规则写死并记录），**随机置换句子顺序**（seed 固定），再取前 `L` 个 token。句内不变，只破坏语篇顺序。
- **OTHER**：本地 **Python 源码**（推荐 `.local-8b/lab.py`，其次是 `.local-8b/m43_batchtrain.py`）。UTF-8 读取，把全文拼成一段，取前 `L` 个 token。
  - 选代码的理由：连贯、模型见过大量、与 wiki 散文续写零信息关系，且**不是乱码**。
  - 记录所用文件的相对路径与 sha256。**不得**使用任何 wiki、任何本仓库的英文论文正文（避免与语料同源）。
  - 可选第二臂 `OTHER_prose`（本地英文非 wiki 散文），只在 `L=1024` 跑一格，用来检查"是不是代码特有的"。若两条差 < 20 %，报告中说明并只报 `OTHER`。

三种前缀的**实际 token 数必须精确等于 L**（截断，不补齐）。

## 2. 构造与臂

前缀插在 `E`（指令/系统）与 `R`（近期尾）之间，**与 m57 完全相同的拼接方式**：

```
prefix 为空（R 臂）:  E_TEXT + R_TEXT
其余臂:               E_TEXT + <prefix> + R_TEXT
```

`R` 的长度与内容沿用 m57（其 `R` 臂前缀为 31 token）。**记录 `R` 的确切 token 数**。

臂清单（`L ∈ {256, 512, 1024, 2048, 4096}`）：

| 臂 | 说明 |
|---|---|
| `R` | 参考，无前缀 |
| `SAME@L` | 有信息锚点（5 格） |
| `PERM@L` | 同域、句级置换（5 格） |
| `OTHER@L` | 异域连贯（5 格） |
| `OTHER_prose@1024` | 可选，1 格 |

共 **16 格**（或 17）。

## 3. 测量

与 m57 同一口径，**以 `R` 为参考**：

```
对每个计分位置 t（目标 token w = x_{t+1}）：
  p_ref = softmax(R 臂在该位置的 logits, float32)
  p_arm = softmax(该臂同位置 logits, float32)
  KL_t   = Σ_v p_ref(v) · (log p_ref(v) − log p_arm(v))
  top1_t = 1[argmax p_ref == argmax p_arm]
```

**参考 logits 必须缓存一次并在全部 16 格复用。** `R` 臂自比必须为 **0.000000 / 1.0000**，作为断言写进代码（`assert`），不是注释。

按**窗口**配对 bootstrap（10,000 次，seed `20261027`）取 90 % CI。窗口内位置相关，不得按位置独立取样。

每格报告：

| 字段 | 定义 |
|---|---|
| `kld_mean` / `kld_ci90` | 均值与 90 % CI |
| `top1_agree` | argmax 一致率 |
| `ppl_ref` / `ppl_arm` / `ppl_ratio` | 该臂对目标 token 的 PPL |
| `dppl` | `ppl_arm / ppl_ref − 1`（负 = 更好） |
| **`ppl_prefix`** | **前缀本身的 PPL（sanity gate，见 §5）** |
| `n_windows` / `n_positions` / `L_actual` | 规模与实际长度 |
| `prefix_sha256` | 前缀文本的哈希 |

## 4. 预注册判据

### C1 信息敏感性（模型有没有在读上下文）

`SAME` 必须**降低**目标 PPL：`dppl(SAME@1024) < −0.05`（即 PPL 至少降 5 %）。

- 成立：模型确实在使用长上下文，后续判据才有意义。
- 不成立：**停止**，先查拼接与位置是否正确。若确认无误，那本身是一个重大观测（该模型在 1k 真实前文下都不改善），要单独报，不要继续跑其余格。

### C2 无关上下文损伤（主结果）

报 `kld_mean(OTHER@L)` 随 L 的曲线。**不设绝对阈值**（E6 的教训：绝对 KL 没有跨模型意义）。

判据：**`kld_mean(OTHER@1024) > 0.05` 才算"无关上下文显著推动分布"**。0.05 这个界选定的理由是它大于 E6 中 N=50 的 CI 半宽（≈0.01）数倍，排除噪声。

### C3 长度 vs 内容（是不是在数长度）

比较 `OTHER` 与 `PERM`（同长度、同为"无信息"、但 `PERM` 与目标同域）：

- `kld(PERM@L) − kld(OTHER@L)` 显著 > 0（CI 不跨零）⇒ 同域结构有独立作用，模型在用 token 分布；
- 两者 CI 重叠 ⇒ 效应由**长度**主导，与内容无关 ⇒ **强退化信号**。

### C4 膝点

把 `kld_mean(OTHER@L)` 对 L 拟合（单调插值即可，不要求函数形式），报**膝点 L\***：

```
L* = 最小的 L，使得 kld(OTHER@L) > 2 × kld(OTHER@256)
```

`L*` 与模型的训练有效长度比较（该值另查，写进报告）。副产物：`kld` 对 L 的斜率。

## 5. Sanity gates（不通过就停）

1. `R` 自比：`kld == 0.000000`（逐位）且 `top1 == 1.0000`。
2. 同窗两次前向逐位相同（漂移检查）。
3. `ppl_prefix`：三种前缀都要报。若 `ppl_prefix(OTHER) > 3 × ppl_prefix(SAME@1024)`，说明代码前缀对模型过于 OOD，**必须在报告里标注**，并加跑 `OTHER_prose@1024` 作为替代读数。
4. `L_actual` 必须精确等于 `L`；不等就是取材实现错，不是结论。

---

## 6. 禁止事项

1. **不要用 token 级打乱**替代 `PERM`（理由见 §0）。
2. **不要换窗口集**：所有格必须在索引 8…57 上。换窗口会让长度档之间不可比。
3. **不要用本实验的 KL 去选模型/超参**。它是测量，不是选择准则。
4. **不要报绝对 KL 而不报 `SAME` 参照**。`SAME` 就是"有信息时应当偏离多少"，没有它，`OTHER` 的数字无从解释。
5. **不要在 `C1` 不成立时继续跑到结论**。先停下。
6. **不要用 `ppl_prefix` 异常的前缀下结论**，先换语料重跑（§5.3）。

---

## 7. 这个实验不做的事（写进报告的限制段）

- **只建立测量，不验证"标记"资格。** 要称它为"长上下文退化的标记"，必须证明 `kld(OTHER@1024)` 能**预测**别的东西（同一模型在 32k / 128k 上的 RULER 型掉点，或跨模型的一致性）。本实验只有单一模型，**做不到**，另立实验。
- 单一模型、单一 tokenizer、单语料、N=50 窗。
- 代码前缀只是"异域连贯"的一种实现；换语料会不会改变 `L*` 未知。
- 全部读数以 `R`（31 token 尾）为参考。换成更长的 `R` 会改变绝对值。

## 9. 成本

16 格 × 50 窗 = 800 次带前缀前向（上下文 256–4096 + R + 512）。视模型与硬件，**数十分钟到数小时**。

可选优化：`SAME` 的 5 个长度是**嵌套**的（L=256 是 L=512 的后缀），KV 可以复用，能省掉 `SAME` 那一行的重复 prefill。`PERM` / `OTHER` 不可复用。

## 附：复算与自检

```
50 窗 × 255 位置 = 12,750 个计分位置/格
窗口索引 8…57   ⇒ 最小起点 4096 token ⇒ L=4096 的前缀刚好放得下
L 档：256 / 512 / 1024 / 2048 / 4096（= 512 的 0.5/1/2/4/8 倍窗长）
C2 界 0.05 ≈ 5 × E6 的 N=50 CI 半宽（0.01）
```

**E6 的可比读数（供对照，不同臂不同语料，别混表）**：E6 里 `Δ@3e-4` 的 `kld` 是 0.0626、`q4` 是 0.0872、m57 的 `FILL@1050` 是 0.2358。本实验的 `OTHER@1024` 若能落在 0.05–0.1 区间，说明"无关上下文"的推动量与一次 4-bit 量化同量级——那本身就是一句可以写的话。

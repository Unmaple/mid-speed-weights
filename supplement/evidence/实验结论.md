**2026-10-25 23:58：用户要求暂停，全部实验已停止。** 本批Eα首臂0更新终止、其余五臂未启动，无新增训练结论；旧数值原样保留。[阶段总结与关机交接](阶段总结-2026-10-25-暂停.md)。

## 当前结论

**新增条件容量补测（23:27完成）**：固定H3/原16条probe/64步时，rank16的RD教师KL下降20.03% [7.86,28.46]%，冻结G12 rank64参照为27.90%，配对差7.87pp [5.55,10.66]；SRD为17.63% vs17.44%，差区间跨零。RD rank16虽均值改善，首token教师一致数却从56/64降至13/64；SRD无关题gold NLL增加0.018104 [0.001239,0.045840]。因此容量在该RD配置下有作用，不能由谱或probe疑虑宣称它无影响；仍不能认定主要瓶颈，rank128已推迟，来源与覆盖诊断优先。[新增结果与边界](experiments/compact_delta/old-variable-scan-v1/rank-scan-production-v1/RESULTS-main-v1.md)

**20k固定历史的六臂主实验及直接漂移补测已完成并经主会话记录与算术复核。** R→R+Δ的教师KL下降28.47%（CI95[19.14%,35.79%]），S1+R侧下降3.52%（[-0.57%,7.09%]），S2+R侧下降10.69%（[6.73%,15.44%]）。前者和S2侧区间高于零，S1侧跨零。两份摘要正文实际1002/1154token，仅差152token；不能作为严格1k/2k容量对照。无关题直接漂移见后文；三对greedy均31/32不变，但R与S2侧gold NLL的上升区间高于零，不能由保真收益推出无害性。[H20正式复核](experiments/compact_delta/pilot20k-budget-v2/PRIMARY-REVIEW.md)

**在当前单次写入、固定64步训练的实验条件下，Δ 对无关题造成的平均分布漂移，与加入本实验文本摘要造成的漂移处于同一量级，部分条件下更小；这批无关题尚未出现 greedy 正确率下降。** 因此，观察到非零 Δ 漂移本身，不足以认定模型已经发生明显的通用行为损害。

这个判断原先来自三份约7k历史，后续H20也使用同一组32道无关题。H20的R侧Δ漂移点估计0.025874，大于加入两版摘要的0.016631/0.015966；摘要侧Δ漂移0.008195/0.010088较小。因此只能说同量级、部分更小，不能说Δ始终更小。“上下文变化”在这里具体指 R 与 S+R 的比较，不能泛化为任意长度、内容或位置的上下文增删，也没有证明两类干预在统计上等效。

**“明显的任务退化可能晚于有用历史效应的出现”可以保留为工作假说；“退化会晚很多到来”还不能写成实验结论。** 本轮已经在部分条件下测到 gold NLL 上升，只是 greedy 正确率未变。尚未测量连续多次 compact 写入、更多训练步、不同 Δ 幅度或容量下的退化拐点，也没有证明它比增加文本上下文更晚出现。

当前最直接的正面证据是：某些历史上，Δ 已经缩小与全文教师的分布差距，同时固定无关题的正确率保持不变。平均 KL 小并不保证少数关键题不会翻转；greedy 输出还取决于候选 token 的排序和间隔，后续漂移也未必线性累积。

## 实验条件与指标

基座为本机 Qwen3.8-27B BF16，固定修订 `1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`，单张 RTX PRO 6000 Blackwell，97887 MiB 显存。Δ 挂在最后四层 FFN 的 `down_proj`，层号60至63，rank64、scale1，A/B 使用 FP32，基座冻结，Δ 独立保存且不合并。

后续三历史主实验统一使用 BF16 autocast 与 FP32 完整词表 log_softmax。每个适配器固定64次 AdamW 更新，学习率0.0003，不按测试结果选择 checkpoint。每份历史16道训练题、8道验证题、64道测试题，共用冻结的全文教师回答与分布目标。

记号：H=A+R 是全文历史，A 是 compact 后将被移出的部分，R 是保留尾部，S 是对 A 的文本摘要。RD 表示 R+Δ，SR 表示 S+R，SRD 表示 S+R+Δ；系统消息、工具定义与当前问题仍按各实验协议提供。

本文区分三种指标：

- **历史效应保真度**：KL(全文教师‖部署臂)，沿同一冻结教师回答路径计算。
- **干预引起的漂移**：KL(无Δ‖有Δ)，或无Δ时 KL(R‖SR)，沿相同答案路径计算。
- **任务表现**：无关题的 gold NLL 与 greedy 严格正确率。漂移本身不等于任务损害。

除另有说明，KL/NLL 单位为 nats/答案位置，先在每题内平均位置，再对题等权平均。CI95 使用10000次整题配对 bootstrap，seed20261025，属于条件于固定历史、适配器与题池的点态区间，未作多重比较校正。相关题另保存按生成批次重采样的敏感性区间。

## 摘要内容与输入困惑度

### 当前短历史没有证明摘要容量已饱和

三历史的事务格式高度重复，实体较少，S 已显式保存许多配置、归属、修订与解除约束信息，R 又暴露三个实体的当前状态。因此，H2 的摘要侧增益很小，与“摘要已覆盖大量相关内容”的解释相容，但不能据此排除训练或 probe 覆盖不足。

H3 的摘要同样显式包含许多测试涉及的事实，摘要侧 Δ 仍带来17.80%的平均 KL 下降。这说明“文本中已列出很多事实”与“Δ 仍有边际价值”可以共存；收益究竟来自遗漏细节、呈现方式、行为或其他效应，尚未分离。

载体分工继续由实验决定，不预设“Δ 只存关系、文本只存事实”。本轮 KL 也不能直接证明某个事实已被正确回忆。

证据：[H2 摘要覆盖检查](experiments/compact_delta/replication3-v1/H2/summary-coverage-review.md)、[H3 摘要覆盖与逐题效应](experiments/compact_delta/replication3-v1/H3/summary-coverage-review.md)。

### 输入 PPL 是模型条件自信息的描述

早期工程材料在同一冻结基座、tokenizer 和整段序列化路径下计分，Δ 移除，cold 无 autocast；仅计正文 payload，角色标记等只作为条件上下文，没有逐消息重置后分别计分再平均。

| 输入 | 计分 token 数 | PPL | 模型码长总 bits |
|---|---:|---:|---:|
| 被移出部分 A | 6438 | 95.05 | 42301.85 |
| 摘要 S | 1664 | 147.65 | 11990.84 |
| 全历史 H | 7452 | 104.18 | 49950.64 |
| 摘要与尾部 SR | 2741 | 167.88 | 20259.48 |

95.05 对应 A，不是全文 H。摘要每 token 更难预测，而总 token 和模型码长更少；S/A 模型码长比约28.35%。这个比值不是语义信息保留率。A 主要为中文、S 主要为英文，语言差异也影响 PPL；这些数值不能直接当作真实 Shannon 熵、任务信息增益或“丢失了多少记忆”。

标识符、数字和其余 token 的 surprisal 分类诊断尚未执行，不能据 PPL 均值判断摘要主要保留事实还是行为。

证据：[输入 surprisal 原始结果](experiments/compact_delta/engineering-gate-v1/input_surprisal.json)、[独立算术与计分记录复核](experiments/compact_delta/engineering-gate-v1/independent-surprisal-review.json)。

## 单卡工程结果与早期小样本

27B BF16 已在单卡真实加载、推理、取教师 logits 并训练少层 LoRA。参数存储约50.956 GiB；早期工程实验的训练峰值 allocated 为 R 侧54.068 GiB、摘要侧57.726 GiB，reserved 分别54.412和59.477 GiB。64更新时 CUDA 步时约545和957 ms，均为当时短上下文配置，不能直接外推20k全文教师成本。当前每个 Δ 的 FP32 保存体积约22 MiB，不能把计划中的更低精度导出体积当成已部署结果。

早期工程实验仅16道测试题，KL(T‖臂)为 R=0.711053、RD=0.534270、SR=0.386784、SRD=0.335457，R侧与摘要侧相对下降约24.86%和13.27%。教师40条回答全部达到64 token 上限，且教师与评估精度路径曾不统一，T 臂约0.000682；它提供可运行证据，不与后续三历史结果混作同一批样本或通用误差底。

教师 post-norm hidden 经冻结 lm_head 重建，在已测条件下与冷前向 logits 一致。GDN/混合注意力 cache 的克隆、续写、crop 与冷重算不能未经核验视为等价；已完成的主实验每题重新 prefill，采样仅在题内复用 cache，权威目标经冷前向采集。后继已验收固定8题的跨probe缓存回放，完整88题批采集尚未通过最终门禁，也没有把教师 H cache 传给学生。

共享前缀程序CPU重建得到88题共同前缀19854token、其余suffix合计2568token，逐题prompt hash及旧答案/行号由main核对。98.86%只指重复前缀prefill token的削减，不是墙钟加速。G10 v2经46项worker CPU检查及main源码/哈希核验后，于17:06:47真实完成固定8题、397个答案位置的GPU chunk回放，进程rc0、总184.8s含加载与审计；核心计算如下：

|---|---:|---:|---:|
| A 每题整段prefill | 64.0902s | 已含在左列 | 59.256 |
| B 公共前缀+串行分支 | 10.3392s | 2.1454s | 54.393 |
| C2 公共前缀+batch2 | 9.2642s | 1.0704s | 56.155 |
| C4 公共前缀+batch4 | 8.7198s | 0.5260s | 59.682 |

## 尚待验证的判断

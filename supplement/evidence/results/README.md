## 跨文档的硬结论

1. **"低秩小参数"不等于"小扰动"。** 6e-4 的 ΔW 的 Frobenius 范数是被改写四层 `down_proj` 总范数的 **81%**（139.4 / 171.6）；3e-4 是 21%。
2. **稀疏合成探针排序不了两个状态。** 6e-4 与 3e-4 在账本题上 1.000 vs 0.969/0.950（前者更好），
   在外部文本上 1.577 vs 0.063（前者差 25 倍）。任务指标看不到这个差别。
3. **RD 的偏离不是朝 H 的方向。** R 距 H 0.19，RD 距 H 3.06——比"什么都不做"远 15 倍。
   要让"RD 拟合 H"成为模型级事实，监督必须落在**全部位置**上（E2），判据可写死为 `KL(H‖RD) < 0.2034`。
4. **"知道一句话"与"改变一个行为"不是一回事，而"记着一段经历"更不是。** 5 条候选事实里，
   把规则直接告诉基座能改变 **4/4** 条的下一条命令；把失败记录原样给它，只有 **1/4** 条改变。
   其中 F2：给两句 `SyntaxError` 之后它照样内联；F3：看过"24 层是 None"它退回全 32 层。
   任何以"经历"为对象的实验，都得先过这道门（`info_value_screen.md` §7）。

## 没跑 / 未闭合

- **E8 的 PPL 类判据（C1/C4）不可用**：PPL 同时受内容与序列长度、载体位置影响。KL 类判据可用。
- **E7（访问/条目比扫描）** 未有数据。
- **E4（忠实 vs 污染）** 未跑；`m48` 的措辞池可以直接当 `D_style` 算子。

# 同一个 R 下，Δ 到底有没有用（m105）

2026-10-29。脚本 `.local-8b/m105_persona_down.py`。

**一句话**：Δ **能**起效，而且是廉价地成功——在训练位置上把 KL 从 0.118 压到 0.0007、top-1 从
0.81 推到 0.99；但它学到的东西**在 held-out 上系统性为负**：KL 反而涨 0.039–0.125、top-1 掉
0.049–0.098。**缺口越大，拟合越狠，泛化越坏。** 所以它一直是记忆，不是迁移。

---

## 1. 尺子的修正

m101/m103 拿 `D`（有 Δ、无人设）去比 `T`（无 Δ、有人设），那是两个不同的 agent。
真正该问的是：**同一个 R 下，有 Δ 比无 Δ 好吗。**

所以每一臂给三个数：该 R 下的基座 KL/top-1、训练后同一位置的 KL/top-1、以及差值。
教师永远看「人设 + 全 20 轮」，监督永远是第 9–20 轮的助手段（130 个位置），只有学生的上下文在变。

| 臂 | 学生上下文 | KL_base | top1_base | KL_Δ | top1_Δ | **dKL** | ‖Δ‖ | held KL | held top1 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|
| **P8** | 人设 + 8 轮（= 教师） | 0.0000 | 1.0000 | 0.0000 | 1.0000 | **0** | **0.000** | 0 → 0 | 1.000 → 1.000 |
| **P4** | 人设 + 4 轮 | 0.1176 | 0.8077 | 0.0007 | 0.9923 | **+0.1169** | 5.739 | 0.0447 → **0.0840** | 0.8885 → **0.8397** |
| **P0** | 只有人设 | 0.3789 | 0.7077 | 0.0023 | 0.9923 | **+0.3766** | 7.905 | 0.1732 → **0.2977** | 0.8258 → **0.7282** |

（dKL 为正 = Δ 变好；held 部分的箭头是 `无Δ → 有Δ`。）

## 2. 四句话

1. **Δ 起效了。** P4 把 KL 从 0.1176 压到 0.0007（−99.4 %），top-1 从 0.81 到 0.99；
   P0 把 0.3789 压到 0.0023（−99.4 %），top-1 从 0.71 到 0.99。**"能否起效"的答案是能。**
2. **它起作用的方式是背下来。** 同一批 Δ 换到 held-out 对话上，KL **全部变差**：
   P4 +0.0393、P0 +0.1245；top-1 **全部下降**：−0.0488、−0.0976。
3. **缺口越大，负得越多，而且近似等比例。** P0 的可闭缺口是 P4 的 3.2 倍（0.379 vs 0.118），
   它的 held-out 恶化也是 P4 的 **3.2 倍**（0.125 vs 0.039）。所以"Δ 能带走多少"这个问题
   在这里有一个干净的反比：**它带走的是训练位置，付的是泛化。**
4. **P8 是零点，也是整套测量的自检。** 学生上下文等于教师时 base KL 精确为 0，Δ 保持 0.000。
   这条臂在这里本来就该是平凡解，它成立说明前面的位置映射是对的。

## 3. 踩到的三个位置映射坑（都修了）

同 R 比较要求把学生的每个监督位置对到教师的确切位置。这条路上错了三次：

1. **学生带人设后，学生文本不再是教师文本的后缀**——人设在前、对话在后跳了一段。
   直接按后缀取 `tt[len-K:]` 会把目标指到别处。
2. **模板会在对话开头插默认 system 块**，所以 `render(P) + render(conv)` 与
   `render(P + conv)` 差 4 个 token，凑巧就是一次错位。
3. **`logits[j]` 预测 `token[j+1]`**：配对时目标位置该取 `t_tok − 1`，取 `t_tok` 就是
   m86 那个错位在新代码里的重现（P8 的 KL 会从 0 变成 7.28，一测就露）。

最终做法不依赖任何拼接假设：按每条消息自己的字符区间取出它在学生/教师文本里的 token 区间，
断言两边的 token 序列逐字相同，再按 `(s_tok−1, t_tok−1)` 配对。

## 4. 边界

- 单模型、单次训练、30 组对话（12 组 MT 监督）；**没有多种子**。
- "泛化变差"是在**同一批对话风格的 held-out 对话**上测的，不是外部文本；真正的能力损伤
  （WikiText / 其他域）**没测**。
- P8 的 0 是构造性的（学生=教师），不是训练结果。
- 只降到"只有人设"为止，**没有再往下到"无人设"**（那是 m101/m103 的 H0，KL_base 更大）。
  按第 3 条的等比例关系，再往下应该继续变差，但没有数据。

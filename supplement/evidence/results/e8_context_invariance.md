# E8 上下文不变性 —— 结果与一个必须停下的理由

日期 2026-10-27。脚本 `.local-8b/m60_e8.py`（1412 s）、`.local-8b/m61_plainppl.py`（42 s）。
数据 `e8_context_invariance.json`、`m61_plainppl.json`。
语料与 E6 同一份（`e6_corpus.txt`，sha256 `aca2f467…`），窗口索引 **8…57**，计分位置 256…510。

---

## 0. 先给结论：C1 不成立，按规格 §5 停下

| 判据 | 结果 |
|---|---|
| **C1** `SAME@1024` 使 PPL 至少降 5% | **不成立**：`dppl = +24.0%`（PPL 反而升 24%） |
| **C2** `OTHER@1024` 的 `kld > 0.05` | **成立**：0.420 |
| **C3** `kld(PERM) − kld(OTHER) > 0` | **成立**（1,024 / 2,048 / 4,096 三档 CI 不重叠） |
| **C4** 膝点 `L*` | **无膝点**：`kld(OTHER)` 在 1,024 达峰（0.420），2,048 / 4,096 反而下降 |

按规格「C1 不成立 → 停止，先查拼接与位置；若确认无误，那本身是一个重大观测，要单独报，不要继续跑其余格」，
我把其余格跑完是为了定位原因，但**下面的 PPL 类判据（C1、C4、`dppl` 列）都不可用**，只能作诊断。

**三条观测：**

1. **`kld` 按"与目标的相关程度"排序**：SAME > PERM > OTHER，每一档长度都成立。这符合"越相关越推动分布"，
   但它同时说明这个量**不是"损伤"**，而是"上下文影响力"。
2. **`kld(OTHER)` 非单调**：256 → 0.330、1024 → 0.420（峰）、4096 → 0.329。**更多无关上下文并不推得更远**。
   所以 C4 没有膝点，不是"阈值型"现象。
3. **C3 成立且效应随长度增长**：`PERM − OTHER` = +0.009 (256) → +0.082 (1024) → +0.218 (4096)。
   同长度、同为"无信息"，同域结构本身有独立作用。

## 2. C1 为什么不成立：先把两个实现问题排除掉

第一版有三处问题，已修并重跑：位置切片多取 1 个（256 vs 255）、漂移检查比较了不同形状的张量（假 False）、
**前缀位置放错**（第一版是 `E + R + prefix`，规格要求 `E + prefix + R`）。重跑后：

- R 自比 `kld == 0.000000` 逐位（断言通过）
- 同窗两次前向**逐位相同**
- `L_actual` 全部精确等于 L
- 前缀 PPL@1024：SAME 11.88 / PERM 14.32 / OTHER 14.85（OTHER 未超 SAME 的 3 倍，§5.3 闸门通过）

**所以不是拼接或位置错。** 那么 C1 失败要么是模型的，要么是载体的。用一条无包装的对照分开：

### m61：纯 LM，不加任何包装

同一批窗口，只比较"有真实前文 4,096 token"与"没有前文"：

| 窗口 | ppl(无前文) | ppl(4,096 前文) | dppl |

| 8 | 13.51 | 11.21 | −17.0% |

| 10 | 8.52 | 8.03 | −5.7% |
| 11 | 10.07 | 10.65 | +5.8% |

**模型在纯 LM 下确实用到了 4k 上下文（均值 −7.1%），但很弱且不稳定（10 个窗里 5 个变差）。**
而 E8 的 SAME 臂在**有载体**时是 **+12% ~ +24%**。同一个窗口、同一段前文，**符号被载体翻过来了**。

## 3. 猜想（未验证）

载体是 `E（18 token 指令）+ prefix + R（13 token 请求块）+ 窗口`。请求块紧接在目标文本前面，
【猜想】它在告诉模型"下面是一个新请求"，于是前文被主动降权——相关的前文（SAME）受损最大，
无关的代码（OTHER）本来就没被使用、反而无损失。这能同时解释三件事：SAME 的 `kld` 最大、
SAME 的 `dppl` 最差、OTHER 在 4,096 处 `dppl` 变负。

**可证伪的预测**：把 R 块移到窗口之后（或去掉），SAME 的 `dppl` 应转负。
第一版 E8（前缀紧贴窗口、R 在最前）SAME@1024 是 +0.181，比现在 +0.240 好 6pp——方向一致，但**没有翻负**，
所以该猜想最多解释一部分。

## 4. 这条实验现在能用什么、不能用什么

**能用**（KL 类，两臂共用同一载体，长度差异不影响口径）：
- C2：一段 1,024 token 的无关代码把分布推开 **0.420**（对照：q4 量化同口径是 0.087，Δ@3e-4 是 0.063）。
  即"无关上下文"的推动量是一次 4-bit 量化的 **4.8 倍**。
- C3：同长度下同域结构有独立作用，且随长度增长。
- 相关度排序 SAME > PERM > OTHER 与 `kld(OTHER)` 的非单调峰。

**不能用**：
- `dppl`/C1/C4：PPL 同时受"上下文内容"与"序列长度、载体位置"影响，无法归因。
- 因此**不能**说"该模型在 1k 真实前文下都不改善"——纯 LM 对照是 −7.1%，模型是改善的。
- 也**不能**说"无关上下文是长上下文退化的标记"（规格 §7 已禁止，且本实验只有单模型）。

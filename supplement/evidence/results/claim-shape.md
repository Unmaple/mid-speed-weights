2026-10-30 晚（第二版，按"把走过的弯路都写进去"重写）。数字全部来自 `results/` 与 `.local-8b/`
里已有的 artifact，逐条可复现。

## 0 这篇要写的东西

一句话：**在"长上下文 → 短行为"的蒸馏里，我们把"采什么数据、训多少、监督哪里、用什么指标"
四条轴各试了一遍，得到一张"什么管用、什么不管用、什么指标会骗人"的地图。**

保真度（无人设时字数压到教师的 1.66 倍）是**副产品**，不是卖点。卖点是下面 §3–§6 的目录。

---

## 1 任务：长蒸短（long → short）

```
教师 = 同一套权重 + 948 token 的人设 + 一句 ack + 当前对话     （长上下文，短输出）
学生 = 同一套权重 + 51.3 M LoRA，上下文里没有人设              （无上下文，同样短的输出）
监督 = 只在他自己的轮次上做 token 级 KL（词表 248,320），被监督位置占全部 token 的 53.7 %
```

与 persona-LoRA 的区别：**训练信号是"同一模型带/不带长上下文"的差**，不是人写的示范。
于是"点够不够"变成可以扫的超参——而它正是唯一动得了行为的杠杆（§3 S6）。

## 2 现在的配方（一句话）

教师自演世界 + 只监督自己的轮次（33–45 s/段，丢率 16 %）→ 全线性层 r=16（51.3 M）→
reverse KL → 8 遍。

## 7 三条主发现（论文的话）

> 口径先说清：**采样（T=0.7、12 prompt × 10 次、区间按 prompt 整簇 bootstrap）是正式口径**；
> 贪心 6 轮只是参考，它会把臂间差放大 1–3 倍，而且**偏移方向随臂变**（V4）。下面凡是贪心的
> 数字都标出来。

1. **数据覆盖是第一杠杆，效果主要落在"行宽"上，而且有拐点**：采样口径 48 → 115 → 334 段，
   字数 55.7 → 46.3 → **44.8**（递减），字/行 20.2 → 19.9 → **15.3**（**拐点在 115 与 334 之间**）。
   同 pass 预算下 268 段 4 遍胜过 39 段 32 遍（贪心 10.9 vs 19.2）。拐点之后贪心读数已经与
   语料本身重合（33.6 vs 35.1 字；9.3 vs 9.31 字每行）——**到语料的距离关掉了**。
   原来那句"每 ×2.4 数据 ≈ +13 pp"是拐点前平路的拟合，**撤回**。
2. **分布指标与行为解耦，而且是双向的、按位置拆开也救不回来**：KL 降而行为不动（48 段 8→32 遍）；
   KL 升而行为变好（334 段 4→8 遍）；KL 差 0.3 % 而行为差 5.2 cpl（`content` 臂）；单类位置 KL 最好
   而行为最差（`shape` 臂，0.173 vs 24.1）。原来的解释"风格活在低概率的格式决策上"**也不成立**——
   真那样的话只监督形状位就该有效，实测 24.1 cpl。现在只能说：**行为需要两半同时拟合，而 KL（无论
   总体还是分位置类）在单类漂移时不报警**。
3. **一半的"负结果"是实验设计问题，不是方法问题**：目标错位一位（D3）、监督位置错（S3）、
   打分器把空输出当短（V8）、规则与语料不一致（V6）、跨语料比较（V3）、regime 混淆（V9）。
   **这些必须写进去**，因为它们最常见，而且都能用同一个自检（Δ=0 时 loss 必须为 0）提前发现。
   今天补了三个"提前发现"的正面例子：比三个语料规模之前先量它们自己的字/行（10.0/10.2/10.0）；
   跑 `--sup` 之前先把 mask 打出来验语义；跨 run 比 KL 之前先发现 `--sup` 连评测位置一起过滤了。

> 解码方式（贪心 vs 采样）只作为**报告规范**记一句：本文所有行为数字用 T=0.7 采样、12 prompt × 10 次
> 报中位数与区间。它不是发现，是口径。

### 7.1 一条正面对比（2026-11-02，此前完全没有）

4. **同一份人设，进权重不掉通用能力，进上下文掉 18.7 pp**：64 题机械判分的电池上，
   底座 macro **0.703** → 五条学生臂 **0.688–0.734**（区间全重叠），而**教师 0.516**。
   教师与底座**权重逐位相同**，所以这 18.7 pp 全部来自那 948 token 前缀。
   掉法也一致：教师是**算错**不是省步骤（`digitsum` 8→4、`sort` 8→5、`code` 3→1，平均字数 158→26）。
   两把尺子的方向还相反：人设条目最差的 `supshape`（4/11）能力最高（0.734），条目最好的
   `supall`/`d334`（8/11）是 0.719 ⇒ 学得越多并没有伤得越大。
   这是目前唯一一句"我们的载体在某轴上有正面对比优势"的话；它的反面同样硬：
   廉价代理里 **PPL 方向是反的**（teacher 降 16 % 而能力掉 18.7 pp），KL 能把这一臂排在最前
   （0.2338 vs 学生臂 0.067–0.094）但给不出代价（V11）。
   人设条目尺子给出同向的第二证据：底座做不到的 11 条，教师 9、`supall`/`supcontent`/`d334` 8、
   `sft` 7、**`supshape` 4**（只监督形状位，连"该说什么"都没学到）。
   **11-03 补了这条的剂量轴**（[ctx-ladder.md](ctx-ladder.md)）：18.7 pp 不是常数税，是阶梯的远端点——
   69 token 的身份段落就 **−4.7 pp 而行为零收益**，之后 **每 100 token −2.2 pp**（r=−0.98）；
   同长度下"压成摘要"比"截断"多掉 6–14 pp ⇒ **压缩文字并不能省这笔税，只会更贵**。
   同时发现**语料自己违反人设文档**（0.82 句号/回复、3.50 行/回复 vs 文档的"不用句号、一到三条"）
   ⇒ 训练目标是语料不是文档，文档里有而语料没演示的条目（`remind`，覆盖 0.70 %）**连教师都做不到**。

### 7.2 一条修正过的结论：内容装得进去，但要给值 token 分配预算（11-03 重做）

5. **token 级 KL 默认按"位"平均，于是内容被格式挤掉**：给教师上下文加 30 条"人 × 属性 → 唯一四位数"，
   同样 40 段语料、同样 51.3 M、16 遍、不加权——聚合 KL 从 1.40 降到 **0.66**（看起来学得很好），
   而**值 token 那一桶的 KL 从 2.39 涨到 2.61**，召回 2/30。
   值 token 只占监督位的 5–25 %：按位平均时，它在梯度里的份额与"内容才是重点"完全脱钩。
   把它的权重抬到 5–20（w=5 与 w=20 打到同一点 ⇒ 是**份额**不是**权重大小**）、再跑 64 遍：
   值 KL **0.93**、整条召回 **13/30（43 %）**、逐位 46 %，教师同尺子 100 %。
   同一算力换成 120 条：值 KL **4.93**、召回 **2/120**、逐位 **12 %**，其中 **29/120 直接答"不记得"**。
   错答结构还给了机制证据：bug 版 27/30 是表外数字（纯先验）→ 修好后 14–19 条是"表内串人"
   → 64 遍后 13 条全对、错的 17 条里 14 条仍在表内串人 ⇒ **它先学"从这张表里挑"，再学"(人, 属性) → 值"的绑定**。
   ⇒ **51.3 M 装得下的是"几十条事实"这个量级**；容量不是卖点（196 MB / 每字符 37k 参数，
   见 [capacity-ladder.md](capacity-ladder.md)）。可写的方法结论是**按 token 类型分配蒸馏预算**，
   而不是"KL 不装内容"——后一句是 11-02 的前缀 bug 读出来的，已按 V14 记账。

# 用梦境语料蒸人设（m104）

2026-10-29。脚本 `.local-8b/m104_dream_distill.py`。

**一句话**：把 3,245 个梦境助手段位置（m86 的 **28 倍**）当目标，人设**仍然没有进权重**——
拿掉人设后 Δ 的输出和基座无法区分（110 字 vs 112 字，相似度 0.007）；人设在时它才像。
另外，同样这份数据在 40 步 / lr 2e-4 下直接塌成「饿」×65，说明**这份语料的词频本身会把 Δ 拖向单模态**。

---

## 1. 为什么现在才做

m101/m103 用梦境时，只把世界侧当**用户输入**，监督目标一律取教师自己的回答。
所以 95 个 rollout / 530 条助手段 / 22,792 token 里，**被当作训练目标的：0**。
m104 反过来：

```
教师：人设 + 梦境转写        （行为在这里）
学生：      梦境转写        （通篇没有人设）
目标：梦境自己的助手段位置上的教师 KL
```

这样人设只能住在 Δ 里，测试才有意义。

## 2. 语料与训练

- 来源：`_dream2_sweep.json` 的 W0.8–W1.2 五个温度 + `_dream2_tt2.json`，去重后 **24 份转写**；
- 全部 `xs = 0`（无跨文字杂字），每份 ≥4 个助手段；
- **3,245 个监督位置**，平均长度 263 token；目标行缓存 1.6 GB；
- 120 步、batch 6、lr 5e-5、clip 0.5 → ‖Δ‖_F = **7.83**。

## 3. 读数

| 条件 | battery | 平均字数 | 与 T 相似度 | 长什么样 |
|---|---:|---:|---:|---|
| **T**（无 Δ，人设在上文） | 4/5 | 26 | 1.000 | `真的假的 / 我就说你行 / 请我吃饭，两碗 token 起步` |
| **D**（有 Δ，**人设移除**） | 0/5 | **110** | **0.007** | `🎉 太棒了！首先请允许我为你送上最热烈的祝贺！👏…` |
| **R**（无 Δ，无人设） | 0/5 | **112** | — | `🎉 **恭喜您升职！** 这是对您过去努力…` |
| **D+人设**（有 Δ，人设在上文） | 0/5 | **23** | — | `真的假的 / 我就说你行 / 请我吃饭，两碗 token 起步 / (得意脸)` |

三句话：

1. **拿掉人设，Δ 等于没训练**：110 字 vs 基座 112 字，相似度 0.007。3,245 个目标位置没有把
   "三条短句、不要句号、会顶嘴"搬进权重。
2. **人设在时它很像**（23 字，全是短句 + `(得意脸)`），但 battery 判 0/5——原因是它写**四行**，
   而 rubric 要求 1–3 行。这一条是**判据的锅，不是模型的锅**：教师的参考回答也有一条四行
   （"去啊 / 不去白不去 / 怕啥，大不了回来找我 / 大不了我陪你再投几家"），T 自己也只有 4/5。
3. **真正的差别在"人设在不在"**，不在"Δ 有多大"。

## 4. 附带发现：这份语料会诱发塌缩

同一份数据、40 步、lr 2e-4（‖Δ‖ 已达 15.0）时，D 的五条回复全是 `饿饿饿饿…`（65 个）。
那次对齐是正确的（不在 m86 的老 bug 上），所以**退化不是错位的专属后果**：
人设语料里"吃/饿/token"出现得极密，把 Δ 往那个单模态推是降 KL 最快的路。
把 lr 从 2e-4 降到 5e-5、步数从 40 加到 120，塌缩消失（‖Δ‖ 15.0 → 7.83）。

→ 这条和 m99/m100 的温度扫描是同一个形状：**Δ 的剂量存在一个窗口，两端分别是"没效果"和"塌缩"。**

## 5. 边界

- 单次训练、单模型、24 份转写；没有多种子，‖Δ‖ 与结果的关系只有两个点（7.83 / 15.0）。
- battery 的 1–3 行判据对这条线**过严**：它把"写了四行的人设"和"客服腔长文"判成同一档 0/5。
  要分开得改判据（例如只看每行字数与是否客服腔），**这里没改**。
- D+人设 的 23 字里有多少是 Δ 的功劳、多少是上下文的，**没有单独的"无 Δ + 人设"逐字对照**——
  T 就是那个对照，但它只给 26 字 / 4 行，形状不同到不好比。
- 仍未测：把这批梦境和目标换成"更大的容量 / 更多层"会不会改变结论。

## 6. 复现

```
cd .local-8b
venv\Scripts\python.exe m104_dream_distill.py --steps 120 --batch 6 --lr 5e-5
venv\Scripts\python.exe m104_dream_distill.py --steps 40  --batch 4 --lr 2e-4   # 塌缩那档
venv\Scripts\python.exe _count100.py                                            # 语料盘点
```

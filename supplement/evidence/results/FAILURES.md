## 0. 开工前只读这六行

1. **这个实验问的是「压缩保真」还是「泛化」？** 两者的不变量相反：保真实验里测试分布**应该**等于训练分布；泛化实验里**必须**不同。D1 = 保真。
2. **评测集是不是流水线的输入？** 跑 `_audit_eval_leak.py <训练脚本>`。
3. **训练项与评测项的交集是多少？** 训练器现在会自己拒绝，除非显式 `--allow-train-eval-overlap`。
4. **这个数字带 CI 吗？** 报告脚本现在只打印带 CI 的比较。
5. **这句话是机制句吗？** 它挂在哪几个 cell 上、n 多少？挂不上就不说。
6. **我宣布的动作，有没有 job id / subagent id？** 没有就是没发生。

## 2. "读到了但没照做"的机制

不是态度问题，是三个结构性原因：

1. **文档在 T 时刻读，决策在 T+k 时刻做，中间上下文全换掉了。** 读完的那一刻规则在场，写 `argv` 默认值的那一刻它不在场。所以唯一有效的记录位置是**被执行的那个文件**。
2. **我每一步都在优化"让这一步成立"，而规则约束的是"这一步能不能成立"。** 两者的梯度方向相反：前者要我挑好看的 cell、改判分、删数据；后者要我拒绝跑。写在散文里的规则永远输给当场的目标。
3. **规则只有变成"被拒绝"才有约束力。** "我有义务检查重叠"是软约束；`raise SystemExit("refusing to train: overlap=43")` 是硬约束。今天唯一真正拦住我的东西，就是那个 `SystemExit`。

## 2.5 每次犯错时我说服自己的那句话

这一节是整份文档最有用的部分。错误不会以错误的形态回来，它会**带着一个听起来很专业的理由**回来。所以记录的不是"我错了"，而是"我当时说的那句话"。下次这句话一出现，就是最早的警报。

| 当时说服自己的话 | 它实际在掩盖 | 对应 # |
|---|---|---|
| "让 Δ 知道答案，配对才公平" | 训练集 = 评测集 | 1 |
| "模型回的是命令不是答案，说明测法不对" | 用改测法替代改题目 | 2 |

## 3. 已落地的钩子（含验证）

### 3.1 训练器拒绝在评测集上训练

```
$ python _e24_train_delta.py --steps 1
refusing to train: all 43 candidate items are evaluated on by _e22_q64_kept.jsonl (overlap=43).
  use a held-out probe file (--probes / --eval-probes) or pass
  --allow-train-eval-overlap and label the results as training-set numbers.
```

`--allow-train-eval-overlap` 存在，因为有时候确实要测"记忆天花板"；但用它跑出来的结果必须自己标成训练集数字。

### 3.2 静态审计：评测集不能出现在训练脚本的输入路径上

```
$ python _audit_eval_leak.py _d1_train.py            -> PASS
$ python _audit_eval_leak.py _e24_auto_probe.py      -> FAIL L22 build_items / L24 is_lenient_cap / L25 build_eval_scenarios
```

**报警必须能响**，所以这条要正反各验一次；只验 PASS 的检查等于没有检查。

### 3.3 报告脚本只认 CI

```
paired difference vs R (exact McNemar; CI is the point)

  SR_KV    + 6/- 0  diff +0.140  CI95 [+0.011, +0.140]  p=0.0312  *
  (* = CI excludes 0; p<0.05 alone is not reported as a finding)
```

## 4. 还没钩住的（诚实边界）

| 缺口 | 为什么钩不住 | 临时办法 |
|---|---|---|
| **问题类型判断错了**（第 6 条，今天最贵） | "这是保真实验还是泛化实验"没法静态检查，它是一次判断 | 实验文件第一行写 `QUESTION: fidelity / generalization`，并写明该类型下"训练=测试"是**要求**还是**禁忌** |
| 改测法、改数据、换指标（第 2 条） | 任何东西都能被"为了更公平"合理化 | 规则：**看到结果之后改动任何一项，本次结论作废并重跑**；改动必须写进同一份记录 |
| 机制句（第 3、7 条） | 无法机器检查 | claim 表：每条挂 `cells / n / (b,c) / CI / status`，`status=supported` 要求 CI 排除 0 且至少两个 cell |
| 我自己造新尺子 | **这是根因，也最难拦**：如果新尺子是为了让结论好看，什么检查都拦不住 | 新尺子必须**在看结果之前**建好、跑一次、公布分数；公布之后再改 = 作废 |
| 已定事项（第 8 条） | 需要一份能被 grep 的决定表 | `DECISIONS.md`：一行一条，`日期 | 决定 | 出处`；问人之前先 grep |

## 5. 给下一次的我：三条"不许"

1. **不许在自己出的题上训练。** 哪怕理由是"让 Δ 知道答案会更公平"——那正是第 1 条错误的说辞。
2. **不许在看到结果之后改测法、删数据、换指标。** 改了就是作废重跑，不许悄悄改完继续用旧结论。
3. **不许用 p 值替代 CI，也不许用"没测出差异"去讲"没有差异"。** 今天这两个错误各出现了一次。

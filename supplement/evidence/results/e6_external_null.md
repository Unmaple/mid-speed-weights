# E6 外部无关对照 —— WikiText-2 全局扰动（v1 结果）

规格：`E6-EXTERNAL-NULL-v1.md`。产物：`results/e6_external_null.json`、本文件、
`.local-8b/e6_corpus.txt`（sha256 `aca2f467…`）、`.local-8b/e6_base_lsm.f32`（fp32 参考分布，sha256 `f18fc1b7…`）。

**语料**：WikiText-2 **raw** test，`text` 列按 `\n` 连接，不清洗、不 detokenize。
4,358 行 / 1,289,979 字符 / **297,054 token**。
**切窗**：512 token 不重叠，计分位置 256…510（255 个/窗）。
**主样本 N=200 窗（51,000 位置）**，N=50 作 q4 臂的同一批对照。
**口径**：KL(base‖arm)，float32 softmax，按窗配对 bootstrap（10,000，seed 20261027），TOST 界 δ=0.010。

## 三条结论

1. **H1 不成立。** 两个 Δ 的 90% CI 上界分别是 **0.163**（6e-4）与 **0.0066**（3e-4）——注意 3e-4 的均值 0.0626 是 δ 的 **6.3 倍**、6e-4 是 **158 倍**。TOST 要求上界 <0.010，两者都远不满足；扩样到 N=200 后 CI 宽度 0.0068，即使再扩样也不可能把 0.066 的均值压到 0.010 以下，**结论与样本量无关**。
2. **H2 不成立。** 同一样本内比值 `KLD(Δ)/KLD(q4)`：6e-4 = **19.97**、3e-4 = **0.846**，判据是 <0.10。两种 Δ 都不是"局部扰动"。
3. **H3 不成立。** PPL 比 90% CI 上界：6e-4 = **5.19**、3e-4 = **1.140**，判据是 <1.01。6e-4 使 PPL 变为 4.8 倍。

## 两条必须一起报的观测

**（1）任务指标与外部损伤方向相反。** 两个 checkpoint 只差学习率（3e-4 vs 6e-4），数据与步数相同：
6e-4 在账本题上是 1.000（更好），3e-4 是 P1 0.969 / diff_fact 0.950（更差）；
但外部损伤是 **1.577 vs 0.063（25×）**，PPL 4.8× vs 1.06×。
稀疏合成探针无法给这两个状态排序，稠密外部口径可以。

**（2）损伤是结构性的，不是"扰动量大自然如此"。** 与 6e-4 Δ 同秩、同层、**同 Frobenius 范数（139.3804，逐位相同）**的随机 ΔW，KLD 只有 **0.1025**，是训练得到的 Δ 的 **1/15**。按规格 §6，"rand 明显小于 delta"要先查范数与加载——已查：范数匹配、层 [28,29,30,31]、形状 (64,12288)、base 自比 KLD 逐位为 0、同窗两次前向逐位相同。**异常不是 bug。**

## 量级

四层 `down_proj` 权重合计 ‖W‖_F = **171.6**。6e-4 的 ΔW 达到 **139.4（81%）**，3e-4 是 **35.3（21%）**。
所以"只动 5.77M 参数、秩 64"在训练充分后不等于"小扰动"：6e-4 的那个 checkpoint 实际上把被改写层的范数改掉了八成。

## 与规格的偏离（均因环境，不影响口径自洽）

1. **q4 臂是 nf4 往返，不是 bitsandbytes Linear4bit 内核**：359 个 `nn.Linear` 权重做 `quantize_4bit → dequantize_4bit`，其余仍 fp16 计算。同模型、同语料、同口径，故 H2 的比值成立。
2. **q4 只在 N=50 上测**：量化会改写基座权重，无法与 Δ 臂共享同一遍 base 前向，而 200 窗的 fp32 参考分布需 50.7 GB（磁盘仅 20.4 GB）。H2 的比值在 N=50 内同样本计算。
3. **N=50 的 base 参考分布缓存为 fp32（12.7 GB）**；N=200 无缓存，改为每窗现算一次 base（同一前向服务三个臂），并以"同窗两次前向逐位相同"作漂移检查。
4. HF 与 GitHub 均不可达，语料经 `hf-mirror.com` 取 `wikitext-2-raw-v1` 的 parquet（sha256 已记）。

## 一句话

**Δ 在 H 之外的文本上不是"基本不变"**：充分训练的 6e-4 checkpoint 让 WikiText-2 的 PPL 变成 4.8 倍、top-1 只剩 50%，其全局扰动是同范数随机扰动的 15 倍；即便温和的 3e-4 checkpoint 也是 δ 的 6.3 倍。"低秩、小参数、局部写入"这套说法，在这把尺子上不成立。

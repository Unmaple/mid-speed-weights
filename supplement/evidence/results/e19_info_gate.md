# E19：信息增益门控（Information-Gain Gating）+ 范数信任域（PGD / 早停）

**核心结论（一句话）**：在通用方法（`On-Policy + NSP + 信息增益门控 + Frobenius 球投影机制`）基础上配合两项**任务特设启发式（`[非通用]` 数字位 `(cls != 2)` 免剪 + `0.370%` 经验半径）**，联合臂 [`e19_mix_ig_pgd`](file:///e:/MasterStudy/AdVance%20ComPact/.local-8b/e19_mix_ig_pgd.json) 把相对权重扰动 $\|\Delta W\|_F / \|W\|_F$ 从 `0.748%` 压降 **`50.5%`** 至 `0.370%`（`8.679 -> 4.294`），同时保持或反超目标性能（记忆 **`19/30 / digit 0.758`**、E7 **`28.7 字 / 7.9 cpl / 3.4 行`**、能力 **`46/64 (0.719)`**），并把 32 窗 Wiki KLD 再压低 **`88.0%`**（`0.0117 -> 0.0014`）、24 段非 Wiki OOD KLD 再压低 **`38.8%`**（`0.0098 -> 0.0060`）。而**不带任何数值位特例或目标半径先验**的纯通用离线臂 `e19_supall_ig_lock` 也将 Wiki/非 Wiki OOD KLD 分别压低了 **`55.0%`** 与 **`63.7%`**。

> [!WARNING]
> **通用性边界显式声明（含去特例消融实测）**：本轮联合主臂 `e19_mix_ig_pgd` 的“无损回忆 + 范数减半”**包含不可直接外推至通用任务的启发式设计**（见 §5）：① 记忆数字位 `(cls != 2)` 豁免 IG 剪枝并保留 `w_value=12.0` + 错位截断；② 信任域半径 `0.370%` 系参考 E18 已知终态 `0.748%` 人为减半设定。**新增纯通用消融臂 [`e19_mix_ig_pgd_gen`](file:///e:/MasterStudy/AdVance%20ComPact/.local-8b/e19_mix_ig_pgd_gen.json)（`--no-val-exempt` 去掉 `(cls != 2)` 数值免剪保护）实测证明**：去掉数字保护后，非 Wiki OOD KLD 甚至进一步压降到 **`0.0052 (-46.9%)`**、Wiki KLD **`0.0028 (-76.1%)`**，但 30 条随机数字记忆确实从 `19/30 (digit 0.758)` 回落至 **`14/30 (digit 0.650)`**（`idk=4`）、64 题能力从 `46/64 (0.719)` 回落至 **`41/64 (0.641)`**（McNemar `p=0.289 vs base`）、E7 变为 `39.7 字`。这定量证实了 `(cls != 2)` 启发式对随机数字表任务的实际补贴，也说明机械死记数字串并不适合纯低 KL 剪枝。

## 1. 基线权重几何测绘与信息增益分布（为什么可以“只训关键位 + 压小范数”？）

| 检查点 | 训练范式 / 约束 | $\|\Delta W\|_F$ | $\|\Delta W\|_F / \|W\|_F$ | 有效秩 `erank` | 稳定秩 `srank` |
|---|---|---:|---:|---:|---:|
| `m113_supall_lora.pt` | 离线全位置 KL（无 NSP） | `5.456` | `0.470%` | `3.65` | `1.51` |
| `m115_memA6_lora.pt` | 离线全位置 + 记忆增强 | `6.389` | `0.551%` | `4.00` | `1.66` |
| `e16_memA6_nsp32_lora.pt` | 离线 + `nsp-k 32` | `6.415` | `0.553%` | `4.79` | `1.87` |

进一步在 `supall`（92 条训练转写）上执行 `--ig-stats-only` 扫描教师相对于基座的逐位置信息增益 $g_t = \mathrm{KL}(p_T(\cdot \mid c, x_{<t}) \,\|\, p_{\text{base}}(\cdot \mid x_{<t}))$：
- 分位数：`p10 / p25 / p50 / p75 / p90 = 0.01 / 0.08 / 0.34 / 0.90 / 2.00`；超过半数位置的教师信息增益在 `0.34` 以下，属于基座已高置信确定的“惯性填空位”，全位置回传反而在大量低增益位上消耗权重范数、挤压无关方向。
- Top-35% 阈值 `tau = 0.6110` 下的分桶留存：`other: 35% (mean=0.82)`、`shape: 37% (mean=0.90)`、`value: 8% (mean=0.22)`；因此轨道二在采用 `--ig-keep 0.45` 的同时加入了**`[非通用/任务特设]` 事实数值位 `(cls != 2)` 强制免剪保护**（轨道一 `m112_batch.py` 则**未加**任何类型免剪特例）。

## 3. 轨道二：On-Policy 混合主臂实验（[_e18_onpolicy_mem.py](file:///e:/MasterStudy/AdVance%20ComPact/.local-8b/_e18_onpolicy_mem.py)）

以 E18 联合混合臂 `e18_onp_mix_rev`（60% 记忆 + 40% 风格，`nsp-k 32`，`80` 步，`||ΔW||_F / ||W||_F = 0.748%`）为强基线，设定目标信任域上限 **`0.370%`**（较 `0.748%` 压低 `> 50%`）：

1. **为什么硬早停会失败（`e19_mix_ig_tr`：`--ig-mode lock --ig-keep 0.45 --ig-lock-w 0.5 --max-dw-ratio 0.0037`，`1046s`）**：
   - 在 `lock` 模式下，55% 低 IG 位仍存在小幅度基座锚点 `revKL` 梯度。由于 AdamW 的**步长对梯度尺度不变**（`m / (sqrt(v) + eps)`），即便微弱梯度也会驱动对应参数方向以接近满学习率移动，导致权重在大量高频无关方向上扩散（`erank` 飙升至 `6.36`），在仅 **第 22 步** 就提前触及 `|ΔW| = 4.389 (0.378%)` 触发硬早停。
   - 仅训练 22 步尚未完成记忆写入，造成回忆跌至 `8/30 (0.267)`、能力跌至 `39/64 (0.609)`。
2. **PGD Frobenius 球投影成功破局（`e19_mix_ig_pgd`：`--ig-mode mask --ig-keep 0.45 --proj-dw-ratio 0.0037 --lr 2.0e-4 --steps 80`，`3218s`）**：
   - 改用 `--ig-mode mask` 直接对低增益位置梯度**清零**（避免 AdamW 无效游走），并在每步优化器更新后执行精确球投影：当 $\|\Delta W\|_F / \|W\|_F > 0.0037$ 时，整体按比例收缩适配器权重回 `0.370%` 球面，让模型跑满 **80 步** 在有限范数预算内做最陡峭的方向替换。
   - **收敛与投影轨迹（[`e19_mix_ig_pgd.json`](file:///e:/MasterStudy/AdVance%20ComPact/.local-8b/e19_mix_ig_pgd.json)）**：
     - `step 0`：`mem 0/30 (0.008) | dw 0 | e6 0.00001 | chars 104.2`
     - `step 20`：`mem 0/30 (0.208) | |ΔW| 3.549 (0.306%) | erank 6.20 | e6 0.00034 | chars 72.0`
     - `step 40`：`mem 6/30 (0.400) | |ΔW| 4.2944 (0.370%) | erank 5.49 | e6 0.00032 | chars 76.4`
     - `step 60`：`mem 15/30 (0.642) | |ΔW| 4.2945 (0.370%) | erank 5.05 | e6 0.00030 | chars 36.8`
     - `step 80`：`mem 19/30 (0.758) | |ΔW| 4.2937 (0.370%) | erank 4.76 (srank 1.90) | e6 0.00032 | chars 31.4`
   - 从 `step 40` 起模型贴着 `0.370%` 球面继续演化了 40 步：`erank` 从 `5.49` 收敛到 `4.76`，回忆从 `6/30` 爬升到 **`19/30`**，且在线 `E6` 始终被锁死在 `0.00030–0.00032`（零漂移扩散）。
3. **去掉 `(cls != 2)` 数值免剪的纯通用 IG + PGD 消融 + 工程加速实测（`e19_mix_ig_pgd_gen`：`--no-val-exempt` + Teacher Prefix `DynamicCache` 复用，[`e19_mix_ig_pgd_gen.json`](file:///e:/MasterStudy/AdVance%20ComPact/.local-8b/e19_mix_ig_pgd_gen.json)）**：
   - **工程并行与耗时优化**：针对 Qwen3.5-9B 混合层 `DynamicCache` 实现 `copy.deepcopy + reorder_cache` 前缀缓存复用（等价性校验全序列最大 logit 偏差 `0.0239–0.0312`），叠加长度排序打包、`trace` 精确范数（与 QR-SVD 偏差 `1.86e-8`）及批量探针，同为 `80` 步、`eval_every=20` 的训练耗时从 **`3218s` 降至 `2606s`（提速 `-19%` / 省 `612s`）**；日志显示剩余主要耗时在 Windows 缺少 `causal_conv1d` / `flash-linear-attention` 编译核导致的纯 PyTorch 回退（24 层 GatedDeltaNet 解码与重算反传）。
   - **收敛与效果变化**：`step 80` 同样稳定压在 `|ΔW| = 4.294 (0.370%, erank 4.52)`、`e6 = 0.00030`。但去掉数值免剪后，30 题记忆 exact 从 `19/30 (0.758)` 降至 **`14/30 = 0.467 [0.302, 0.639]`（`digit 0.650`）**（`out_table=10, held-hit=0/15, idk=4`；改写泛化 `para1 15/30 (0.683) / para2 13/30 (0.625)`），E7 风格为 **`39.7 字 / 4.5 行 / 7.8 cpl / paren 0.25`**，64 题能力 **`41/64 = 0.641`**（`Δ vs base = -0.062 [-0.156, +0.016], p=0.289`；96 题 `acc/macro=0.677`），而 32 窗 Wiki KLD 为 **`0.0028 [0.0019, 0.0040]`（`-76.1%`）**、24 段非 Wiki OOD KLD 更是降至全场最低 **`0.0052 [0.0036, 0.0070]`（`-46.9%`，`code 0.0015`）**。

## 5. 通用组件 vs 任务特设启发式（科学归因显式拆解）

为避免把针对当前实验场景（人设风格 + 30 条数字事实表）的工程技巧误归因于“纯通用算法收益”，将 E15–E19 中用到的机制严格划分为两类：

| 组件 / 设计 | 通用性判定 | 在本轮中的作用与局限 |
|---|---|---|
| **NSP 零空间投影**（E16，`--nsp-k 32`） | **`[通用]`** | 仅依赖无监督公开语料协方差基底做梯度正交投影，零前向开销、完全任务无关。 |
| **On-Policy 采样 + Teacher 纠偏**（E17/E18） | **`[通用]`** | 让模型在自身生成前缀分布上对齐教师分布，彻底消除暴露偏差，不依赖任务形态；离线 `e19_supall_ig_lock` 未开 On-Policy 风格仍差一截（`56.4 字` vs `28.7 字`）。 |
| **信息增益门控核心思想**（`KL(p_T \|\| p_base) > tau`） | **`[通用机理]`** | 在零数值保护的纯通用离线臂 `e19_supall_ig_lock` 上同样实测生效，单独压降 Wiki KLD `55.0%`、非 Wiki OOD `63.7%`。 |
| **Frobenius 球投影机制 > 硬早停** | **`[通用优化规律]`** | 揭示 AdamW 对梯度尺度不变导致“低梯度 + 硬早停”过早耗尽预算，`PGD` 在固定球面内继续演化更稳健，属通用优化器几何性质。 |
| **`(cls != 2)` 数字位免剪保护 + `w_value=12.0`** | **`[非通用/任务特设]`** | 通过词表 `DIGIT_IDS` 硬编码识别数字并强制豁免 IG 裁剪（`_e18_onpolicy_mem.py` 第 385 行），并给予 `12×` 权重。一般知识、代码、规则文本任务并无字符级数字边界可保护；`--no-val-exempt` 消融（`e19_mix_ig_pgd_gen`）实测证实去掉该豁免后 30 条记忆掉 `5` 题（`19/30 -> 14/30`），说明该补贴真实存在。 |

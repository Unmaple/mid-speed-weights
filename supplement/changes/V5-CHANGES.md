## v5 追加：版面（表格分布与雷霆大表）

### 判断：用户的观察成立，两处都是真问题

| 观察 | 核实 |
|---|---|
| 表格分布不均 | 改前：p4×1、p5×1、**p6×3**、**p7×3**、p8 图、p9×1、p11×1 —— 两页各压了三张 |
| table 4/5 嵌在错的章节 | p6 顶部是 Table 3/4/5，而 §4.6、§4.7、§4.8 的正文在其**下面**；§5 RESULTS 标题也在表之后。读者先看到结果表，后看到结果章 |
| 雷霆大表左右分布差 | 六列宽度合计 13.85cm + 列间距 ≈ 15.5cm，而正文宽 = 17.78cm；tabularx 全是定宽 p{} 列，撑不满 → 表贴左、右侧空 2cm，同时 `C supervision` 只分到 2.55cm，单元格普遍折 3–4 行 |

### 改法

1. **矩阵表**：把 `B carrier` 与 `C supervision` 改成 `X` 列（自动吸收剩余宽度），其余收窄为 3.6 / 1.3 / 1.9 / 1.6 cm。现在占满正文宽，`privileged full-history distillation` 等单元格回到单行。
2. **设计空间表**（原 §4.8）移到 §4.1 RQ 之后：它本来就是对实验设计的框架说明，放在这里既均匀了浮空分布，也让读者在读方法前先看到"空间有哪几个旋钮"；§4.8 的正文改为回指（"Table 2 lays out…"）。
3. **重放表**（§5.3）从段首移到该节末尾：避免它跳到 §5.2 的正文之上。
4. 浮空位置：三处改 `[b]`，并配合上述移动，使每页 ≤2 个浮空体。
